- A function that sets when the values of fields inserted in the drawing are automatically updated.

![][image1]

## **1\. Setting the Field Update Condition** [**Manual Field Update Demo Video**](https://youtu.be/P6mBgFzY_5k)

1\) Run the "FIELDEVAL" command.  
2\) Enter a value between 0\~6 in the Command Input Window.

- 0: No automatic update
- 1: Update when opening the drawing (Open)
- 2: Update when saving the drawing (Save)
- 4: Update when plotting (Plot/print)
- 8: Update when running ETRANSMIT
- 16: Update when regenerating the drawing (REGEN)
- 31: All of the above applied (1+2+4+8+16)

3\) Press Enter after entering the value to apply the setting.
