* A command that controls whether a frame (border line) is displayed for images (Image), external references (Xref), OLE objects, and similar objects in the drawing.

![][image1]

## **1\. Setting Frame Display** [**Demo Video**](https://youtu.be/HHTWoDT_x7o)

1\) Type "FRAME" in the Command Line.  
2\) Enter the value that specifies the frame display state.

| Value | Description |
| :---: | ----- |
| 0 | The frame is not displayed, and it does not appear when printed. |
| 1 | The frame is displayed, and it is also printed. |
| 2 | The frame is displayed, but it is not shown when printed. |

3\) Press the ENTER key to apply the setting.  
Note: If the change is not immediately reflected on screen after changing the value, refresh the display with the "REGEN" command.
