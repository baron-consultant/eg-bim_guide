- A command that rounds the intersection of two selected objects using a specified radius.

![][image1]

## **1\. How to Use** [**Demo Video**](https://youtu.be/hrUtQLmhU30)

- Run the "FILLET" command.
- Select the first object and the second object.
- Or select one of the following options.

* Polyline: All corners of the selected polyline are rounded with the specified radius.
* Radius: Sets the radius.
* Trim: Set to Trim by default.  
&nbsp;- Trim: The original line segments are trimmed away, leaving only the fillet curve.  
&nbsp;- No trim: The original line segments are retained, and the fillet curve is added.
* Settings: Opens the settings window.
* Multiple: Allows the fillet to be applied continuously to multiple pairs of objects using the specified radius.
