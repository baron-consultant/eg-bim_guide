- A function that searches for a specific text string in the drawing and, if needed, replaces it with another string.

![][image1]

## **1\. Finding and Replacing Text** [**Demo Video**](https://youtu.be/FJj3F7gV1Qw)

1\) Run the "FIND" command in the Command Line.  
2\) The Find and Replace dialog box appears.  
![][image2]  
3\) Configure the options.

- Enter the text string to find
- Enter the replacement text string (optional)
- Search scope: Can be set to the entire current drawing, a selection, specific object types, etc.
- Search options: Case sensitivity, whole word match, etc.

4\) Click the Find button to display the matching items.
