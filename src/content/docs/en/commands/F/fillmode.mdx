- A command that sets whether hatches, 2D solids, and wide polylines are filled.

![][image1]

- Setting ON \=\> Fills the inside of the object,  
Setting OFF \=\> Does not fill the inside of the object.

![][image2]

- Setting ON

![][image3]

- Setting OFF

## **1\. How to Turn the Setting On and Off** [**Demo Video**](https://youtu.be/arkY6DvAuI0)

1\) Run the "FILLMODE" command.  
2\) To turn it ON, enter ON or 1 in the Command Line; to turn it OFF, enter OFF or 0 in the Command Line.
