- A function that displays or selects the location of a block inserted in the drawing on screen.

![][image1]

## **1\. Measuring a Radius** [**Demo Video**](https://youtu.be/rl7-iTtnVtw)

1\) Type "FINDRADIUS" in the Command Input Window.  
2\) Following the Command Input Window prompts, click the four points in order.

- Start point: The start point of the arc
- Mid point: The midpoint of the arc
- End point: The end point of the arc
- Center direction point: The point in the direction where the center of the circle lies  
(i.e., click above if the circle curves upward, or below if it curves downward)

3\) The calculated result is displayed in the Command Input Window.
