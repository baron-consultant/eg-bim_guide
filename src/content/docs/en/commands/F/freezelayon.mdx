---
title: FREEZELAYON
---

[image1]: ../../../../../assets/images/en/commands/freezelayon/image1.png

- A command that reverses the frozen state of all layers in the current drawing. That is, layers that are frozen are thawed, and layers that are thawed are frozen.

![][image1]

## **1\. Reversing the Layer Frozen State** [**Demo Video**](https://youtu.be/jCpAzAPdx2w)

1\) Type the "FREEZELAYON" command in the Command Input Window.  
2\) Press the ENTER key.  
3\) Layers that were frozen are thawed, and layers that were thawed are frozen.
