- A function that lets you search for and batch-replace the text of multiple objects in the drawing.

![][image1]

## **1\. Finding and Replacing Text** [**Finding Text Demo Video**](https://youtu.be/1TV2ep1D104) [**Replacing Text Demo Video**](https://youtu.be/M03K36GUu3M)

1\) Run the "FINDANDREPLACETEXT" command in the Command Line.  
2\) Configure the desired options in the FINDANDREPLACETEXT dialog box.  
![][image2]  
3\) Use the Find, Replace, and Replace All buttons to search for or replace the text string.  
4\) Click the Apply button to change the matching text strings and reflect them in the drawing.
