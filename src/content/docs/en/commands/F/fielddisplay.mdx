- A function that controls whether a gray background is displayed instead of plain text when displaying field objects inserted in the drawing.

![][image1]

## **1\. Creating a Field Setting the Field Background Display** [**Demo Video**](https://youtu.be/mVzcT5TtTcQ)

1\) Run the "FIELDDISPLAY" command.  
2\) Select the ON / OFF option in the Command Line.

- ON: Fields are displayed with a gray background → field objects can be easily distinguished
- OFF: Fields are displayed as plain text → shown without a background, as in the printed output

3\) Once configured, all field objects in the drawing are displayed accordingly.  
4\) Click OK to insert the field into the drawing as MTEXT.
