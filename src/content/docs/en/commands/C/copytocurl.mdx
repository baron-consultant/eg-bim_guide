- A command that copies the selected object to the current layer.

![][image1]

## **1\. Copying to the Current Layer** [**Demo Video**](https://youtu.be/syvVSXDe4n4)

1\) Type "COPYTOCURL" in the Command Line.  
2\) Press the ENTER key.  
3\) The selected object is copied to the currently set layer.  
4\) The original object remains on its original layer, and the copied object follows the properties of the current layer.
