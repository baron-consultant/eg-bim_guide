* Changes the display color of an external reference (Xref) object inserted in the drawing.

![][image1]

## **1\. Changing the External Reference Color** [**Demo Video**](https://youtu.be/0boyoua2xd0)

1\) Type "CHXREFXOLOR" in the Command Line.  
2\) Select the external reference (Xref) whose color you want to change.  
3\) Enter the new color value (Color Index, TrueColor, or name).

- Example: `1`(Red), `2`(Yellow)

4\) Press the ENTER key to apply.
