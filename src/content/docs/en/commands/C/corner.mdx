title: CORNER

[image1]: ../../../../../assets/images/en/commands/corner/image1.png

- A command that selects two lines in the drawing and automatically creates or cleans up their intersection.

![][image1]

## **1\. Creating an Intersection** [**Demo Video**](https://youtu.be/DKP7YlyqVKA)

1\) Type "CORNER" in the Command Input Window.  
2\) Following the Command Input Window prompts, select the first line.  
3\) Then select the second line.  
4\) The two lines are automatically extended or trimmed to connect at their intersection.
