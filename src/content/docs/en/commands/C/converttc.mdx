- Converts the content of the selected text object to uppercase, lowercase, capitalize first letter, etc.

![][image1]

## **1\. Changing Case** [**Demo Video**](https://youtu.be/80_mLyhixYc)

1\) Run the "CONVERTTC" command.  
2\) In the CONVERTTC dialog box, select the desired conversion method.  
![][image2]  
3\) Select the text object to convert.  
4\) Press ENTER or the Space bar to convert the case of the selected text according to the specified method.  
![][image3]
