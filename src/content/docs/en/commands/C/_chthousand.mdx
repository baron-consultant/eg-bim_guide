title: CHTHOUSAND
---

[image1]: ../../../../../assets/images/en/commands/chthousand/image1.png

* Automatically adds or removes thousands-separator commas (,) in the numeric values of dimensions or text in the drawing.

![][image1]

## **1\. Adding Thousands Separators** [**Demo Video**]()

1\) Type **"**CHTHOUSAND**"** in the Command Line.  
2\) Select the text or dimension object to apply the comma formatting to.  
3\) Press the ENTER key to display the number in the selected object with thousands separators.
