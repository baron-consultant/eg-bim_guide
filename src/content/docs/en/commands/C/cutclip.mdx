- Cuts the selected object, copying it to the clipboard, and deletes the original object from the drawing.

![][image1]

## **1\. Cutting an Object** [**Demo Video**](https://youtu.be/7Rgv5LWgbNI)

1\) Run the "CUTCLIP" command.  
2\) Select the object(s) to cut (line, polyline, circle, block, dimension line, etc.).  
3\) Press ENTER to complete the selection.  
4\) The selected object is copied to the clipboard and deleted from the drawing.  
Note: Run the "PASTECLIP" command to paste it into the drawing.  
![][image2]
