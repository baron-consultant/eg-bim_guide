- Selects an object inside a block or external reference and copies it into the current drawing.

![][image1]

## **1\. Copying a Block Object as a Regular Object** [**Demo Video**](https://youtu.be/2YJbNnelqWM)

1\) Run the "COPYNESTED" command in the Command Input Window.  
2\) Select the object to copy from a block, external reference (Xref), DGN/PDF underlay, etc.  
3\) Click the object, and paste it using Ctrl \+ V.  
4\) The object is copied into the current drawing's workspace as an independent object.  
![][image2]
