- Automatically moves a text object to the center point of the selected rectangular area or shape.

![][image1]

## **1\. Moving a Text Object to the Center** [**Demo Video**](https://youtu.be/E8sT1jT2SVE)

1\) Run the "CENTERREC" command in the Command Line.  
2\) Select the text object to move.  
3\) Select the rectangular area to use as the center reference.  
4\) Confirm to automatically align the selected text to the center coordinates of the rectangular area.  
![][image2]
