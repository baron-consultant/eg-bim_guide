- Performs direct arithmetic operations (+, \-, ×, ÷) so you can see simple calculation results immediately.

![][image1]

## **1\. Using the Calculator** [**Demo Video**](https://youtu.be/VV-sQZ85kVs)

1\) Type "CAL" or "CALCULATOR" in the Command Line.  
2\) Enter the expression to calculate in the Command Line. Example: 2 \+ 3, 10 / 4  
3\) Press the ENTER key.  
4\) The result is displayed in the Command Line.
