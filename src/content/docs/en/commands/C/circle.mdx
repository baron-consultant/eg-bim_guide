[image1]: ../../../../../assets/images/en/commands/circle/image1.png

- Creates a circle.
- You can create a new circle or convert an existing arc into a circle.

### Circle Drawing Option Keywords

![][image1]

| Option    | Description                           |
| :-------- | :----------------------------------- |
| 2Point    | Creates a circle by specifying 2 points.        |
| 3Point    | Creates a circle by specifying 3 points.        |
| RadTanTan | Creates a circle tangent to two objects.    |
| TanTanTan | Creates a circle tangent to three objects. |
| Arc       | Converts an arc into a circle.              |
| Multiple  | Creates multiple circles.            |

<br />

## **1\. How to Draw a Circle by Specifying Points** [**Demo Video**](https://youtu.be/UOeWKP48X8w)

1\) Run the "CIRCLE" command.  
2\) Select a circle drawing option keyword.  
&nbsp;&nbsp;&nbsp;&nbsp;2-1) Without selecting a keyword, specify the center point and diameter on screen.  
&nbsp;&nbsp;&nbsp;&nbsp;2-2) Enter the 2Point keyword and specify the circle's two endpoints on screen with the mouse.  
&nbsp;&nbsp;&nbsp;&nbsp;2-3) Enter the 3Point keyword and specify the circle's three points on screen with the mouse.  
3\) Once the points are specified, the circle is created and the command ends.

## **2\. How to Draw a Circle Using Objects** [**Demo Video**](https://youtu.be/wcBn6fNxD_s)

1\) Run the "CIRCLE" command.  
2\) Select a circle drawing option keyword.  
&nbsp;&nbsp;&nbsp;&nbsp;2-1) Enter the RadTanTan keyword.  
&nbsp;&nbsp;&nbsp;&nbsp;2-2) Enter the TanTanTan keyword.  
3\) Select objects.  
&nbsp;&nbsp;&nbsp;&nbsp;3-1) For RadTanTan, select the objects to use as the first and second tangent points, then press ENTER or enter a valid radius to create the circle.  
&nbsp;&nbsp;&nbsp;&nbsp;3-2) For TanTanTan, select the first, second, and third tangent points to create the circle.

## **3\. How to Convert an Arc into a Circle** [**Demo Video**](https://youtu.be/MPLWC0yO508)

1\) Run the "CIRCLE" command.  
2\) Enter the Arc keyword.  
3\) Select an arc object to convert it into a circle.

## **4\. How to Draw Multiple Identical Circles at Once** [**Demo Video**](https://youtu.be/HU23pA_KgKI)

1\) Run the "CIRCLE" command.  
2\) Enter the Multiple keyword.  
3\) Select a drawing option, or specify the circle's center point with the mouse on screen to draw the circle.  
4\) Without ending the command, continue specifying center points on screen to keep creating circles identical to the first one drawn.  
5\) To end the command, press the ENTER or ESC key.
