- Copies the selected object to the clipboard, including a base point specified by the user.

![][image1]

## **1\. Copying an Object (with Base Point)** [**Demo Video**](https://youtu.be/HUXQQ25POKI)

1\) Run the "COPYBASE" command.  
2\) First, specify the base point.

- This point is used as the reference when pasting.
- You can specify a vertex, center point, intersection, or other point on the object.

3\) Select the object(s) to copy (line, polyline, circle, block, dimension line, etc.).  
4\) Press ENTER to complete the selection.  
5\) The selected object is copied to the clipboard, including the specified base point.  
Note: Run the "PASTECLIP" command to paste it into the drawing.
