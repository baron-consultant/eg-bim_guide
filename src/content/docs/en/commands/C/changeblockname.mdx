- Renames a block defined in the drawing. You can change the existing block name to a new name, and the updated block name is immediately reflected throughout the drawing.

![][image1]

## **1\. Renaming a Block** [**Demo Video**](https://youtu.be/nmmklpU4cHM)

1\) Type "CHANGEBLOCKNAME" in the Command Line.  
2\) Select the block to rename.  
2\) Enter the new block name in the Command Line.  
4\) Press ENTER or the Space bar to apply.  
5\) All existing block references in the drawing are updated to the new name.  
![][image2]
