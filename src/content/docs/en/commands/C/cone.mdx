[image1]: ../../../../../assets/images/en/commands/cone/image1.png

- Draws a 3D cone parallel to the XY plane.

## **1\. Drawing a Cone by Specifying the Radius** [**Demo Video**](https://youtu.be/X-vIoY7Fzow)

1\) Run the "CONE" command.  
2\) Select the coordinate for the center of the cone's base, then draw a circle whose radius is the distance to the mouse pointer.  
3\) Specify the height to draw the cone.

## **2\. Drawing a Cone by Specifying the Diameter** [**Demo Video**](https://youtu.be/kEKskaiBUCw)

1\) Run the "CONE" command.  
2\) Select the coordinate for the center of the cone's base, then select the Diameter option in the Command Line.  
![][image1]  
3\) Draw a circle whose diameter is the distance to the mouse pointer.  
4\) Specify the height to draw the cone.
