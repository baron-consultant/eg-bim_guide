[image1]: ../../../../../assets/images/en/commands/ctcmark/image1.png

* A command that calculates the CTC (center-to-center spacing) value based on the position of rebar blocks in the drawing and marks it as text.

![][image1]

## **1\. Marking Rebar CTC** [**Demo Video**](https://youtu.be/EJuuV-MIpxs)

1\) Type "CTCMARK" in the Command Line.  
2\) Select a rebar block in the drawing.  
3\) Enter the rebar identifier (RB_NO) value.  
4\) The CTC mark is displayed.
