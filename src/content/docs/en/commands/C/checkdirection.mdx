- Used to check or correct the direction of a polyline or hatch in the drawing.

![][image1]

## **1\. Checking Object Direction** [**Demo Video**](https://youtu.be/_C8gqWSocLg)

1\) Type "SCALEDISTANCE" in the Command Line.  
2\) Select the object whose direction you want to check.  
3\) The current direction of the selected object is displayed on the object.
