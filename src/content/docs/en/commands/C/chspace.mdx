[image1]: ../../../../../assets/images/en/commands/chspace/image1.png

- Moves the currently selected object to another space (Model ↔ Paper) based on the viewport.

![][image1]

## **1\. Switching Object Space** [**Moving an Object to Paper Space Demo Video**](https://youtu.be/iD7QMQcbgsk) [**Moving an Object to Model Space Demo Video**](https://youtu.be/bR84JRNwcq4)

1\) Go to the Layout tab.  
2\) Type "CHSPACE" in the Command Input Window.  
3\) Select the object to move.  
4\) Press the ENTER key.  
5\) The selected object automatically moves between Model Space and Paper Space, and its size is automatically adjusted according to the viewport scale.  
6\) The selected object's scale is automatically adjusted as it moves to the corresponding space.
