[image1]: ../../../../../assets/images/en/commands/copycapturedimage/image1.png

- Captures the current viewport screen as an image and copies it to the clipboard.
- The copied image can be pasted into the drawing or into external programs such as Word, PowerPoint, or Paint.

## **1\. Capturing a Screen Image** [**Demo Video**](https://youtu.be/Getwcj-8iZc)

1\) Select the object to capture.  
2\) Run the "COPYCAPTUREDIMAGE" command.  
3\) The selected object is saved to the clipboard as an image (bitmap).  
Note: You can then paste the image using the "PASTESPEC" command or standard paste (CTRL + V).
