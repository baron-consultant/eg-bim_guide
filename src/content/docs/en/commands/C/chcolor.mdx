- Changes the line weight of the selected objects in a batch.

![][image1]

## **1\. Changing Object Color** [**Demo Video**](https://youtu.be/Mu9IhwISYs0)

1\) Run the "CHCOLOR" command.  
2\) Select the objects (line, polyline, circle, rectangle, etc.) whose color you want to change.  
3\) Press ENTER to complete the selection.  
4\) Enter the color number to apply.  
5\) Press ENTER or the Space bar.  
6\) The color of the selected objects changes to the color corresponding to the entered number.  
![][image2]

## **2\. Color Number Table**

|   Number  |    Color Name   |                      Description                    |
| :------: | :-------------: | :--------------------------------------------: |
|    0     |     BYBLOCK     |         Follows the color of the block the object belongs to |
|    1     |       Red       |                     Red                     |
|    2     |     Yellow      |                     Yellow                     |
|    3     |      Green      |                     Green                     |
|    4     |      Cyan       |                     Cyan                     |
|    5     |      Blue       |                     Blue                     |
|    6     |     Magenta     |                 Magenta                 |
|    7     |  White / Black  |   Displayed as white or black depending on the screen background color   |
|  8 \~ 9  | Light Gray family | Shades of gray                    |
| 10 \~249 | Standard ACI palette | Gradual color spectrum from red to blue to purple to gray, etc. |
|   250    |    Gray 50%     |                   Medium gray                    |
|   251    |    Gray 75%     |                   Light gray                    |
|   252    |    Gray 87%     |                  Lighter gray                  |
|   253    |    Gray 93%     |                 Very light gray                 |
|   254    |    Gray 96%     |            Gray, nearly white             |
|   255    |    Gray 100%    |                   Pure white                    |
|   256    |     BYLAYER      |       Follows the color of the layer the object belongs to       |
