- A command that automatically creates a crosswalk on the drawing.

![][image1]

## **1\. Creating a Crosswalk** [**Demo Video**](https://youtu.be/iBCINlQ4xC0)

1\) Type "CROSSWALK" in the Command Line.  
2\) Set the required options in the settings.  
![][image2]  
3\) Specify the start point of the crosswalk in the drawing.  
4\) Specify the end point of the crosswalk in the drawing.  
5\) Press the ENTER key to automatically generate the crosswalk pattern along the specified section.
