- Draws a cylinder cutting line.
- The cylinder cutting line is drawn using three arc objects.

## **1\. Drawing a Cylinder Cutting Line** [**Demo Video**](https://youtu.be/PDSGVTECyKQ)

1\) Run the "CUTCYL" command.  
2\) Click the mouse to specify the start point.  
3\) Click the mouse to specify the end point.  
4\) Specify the direction.
