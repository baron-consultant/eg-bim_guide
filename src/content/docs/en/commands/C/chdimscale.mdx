* Batch-converts the dimension scale values applied to dimension objects in the drawing by entering a base scale and a new scale ratio.

![][image1]

## **1\. Adjusting the Dimension Scale** [**Demo Video**](https://youtu.be/tDqr0Qwn19A)

1\) Type **"**CHDIMSCALE**"** in the Command Line.  
2\) Following the Command Line prompts, enter the values in the order below.

- Enter base scale value: the existing scale value of the current drawing  
- Enter scale value to change: the scale value to apply

3\) Select the dimension objects to change.  
4\) Press the ENTER key to adjust the scale of all selected dimension objects to match the entered ratio.
