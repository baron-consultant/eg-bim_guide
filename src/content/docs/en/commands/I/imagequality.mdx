- Controls the image quality level of raster images (JPEG, PNG, etc.) inserted into the drawing.

![][image1]

## **1\. Set Image Quality** [**Demo Video**](https://youtu.be/ezq317_5Cmk)

1\) Type the "IMAGEQUALITY" command in the Command Input Window.  
2\) Enter High or Draft as the option.

- High : Displays at high quality \u2192 prioritizes image quality (sharpness)
- Draft : Displays at low quality \u2192 prioritizes performance (speed)
