- Displays only the selected objects in the drawing on screen and temporarily hides all other objects.

![][image1]

## **1\. Restore Hidden Objects** [**Demo Video (Hide All Except the Selected Objects)**](https://youtu.be/i5mXEyJ9hPI)

1\) Run the "ISOLATEOBJECTS" command.  
2\) Select the objects (lines, polylines, blocks, images, hatches, etc.) to display on screen.  
3\) Press ENTER or the SPACE BAR to complete the selection.  
4\) Only the selected objects are displayed on screen; all other objects are hidden.  
Note: Run the "UNISOLATEOBJECTS" command to display the hidden objects again.  
![][image2]
