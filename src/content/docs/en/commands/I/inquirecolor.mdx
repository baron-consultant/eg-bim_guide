- A function that looks up the color information of a selected object in the drawing, letting you check its Index Color and True Color (RGB) values.

![][image1]

## **1\. Check Object Color** [**Demo Video**](https://youtu.be/nyFCqzDJR38)

1\) Type "INQUIRECOLOR" in the Command Input Window.  
2\) The Color Inquiry dialog box appears.  
![][image2]  
3\) Select the required options.  
4\) Selecting an object displays its information in the color list.
