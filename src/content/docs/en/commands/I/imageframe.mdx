[image1]: ../../../../../assets/images/en/commands/imageframe/image1.png

- Controls whether the frame of a raster image inserted into the drawing is displayed and whether it is included when plotting.

![][image1]

## **1\. Usage** [**Demo Video**](https://youtu.be/kIuLQPABawU)

1\) Type the "IMAGEFRAME" command in the Command Line.  
2\) Enter one of the values 0, 1, or 2 as the option.

- 0 : Frame not displayed (no frame on screen or in plots \u2192 image cannot be edited)
- 1 : Frame displayed and plotted (frame shown on screen and included in plots)
- 2 : Frame displayed only (frame shown on screen only, not included in plots)

3\) Press ENTER to complete the setting.
