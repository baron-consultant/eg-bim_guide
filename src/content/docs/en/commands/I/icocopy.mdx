* A command that copies an object in the drawing by specifying a base point, distance, and direction.

![][image1]

## **1\. Copy an Object** [**Demo Video**](https://youtu.be/EW0ZJBBreAE)

1\) Type "ICOCOPY" in the Command Input Window.  
2\) Select the object to copy.  
3\) Specify the base point.  
4\) Click the direction to copy in.  
5\) Specify the distance to copy.  
6\) An identical copy of the object is created at the specified location.
