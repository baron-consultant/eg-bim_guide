* A function that copies lines, polylines, circles, rectangles, etc., inward or outward by a specified distance.

![][image1]

## **1\. Offset** [**Demo Video**](https://youtu.be/qN1knSHlbm8)

1\) Type "INOFFSET" in the Command Line.  
2\) Select the object to offset.  
3\) Select the inward/outward direction for the selected object.   
4\) Enter the offset distance in the Command Line.  
5\) An identical object is created in the selected direction.
