- A command that checks the coordinate (X, Y, Z) values of a selected point in the drawing.

![][image1]

## **1\. Check Coordinates** [**Demo Video**](https://youtu.be/mdeKJlyNqXM)

1\) Type "ID" in the Command Line.  
2\) Click the point in the drawing whose coordinates you want to check.  
3\) The coordinates of the point are displayed in the Command Line.  
![][image2]
