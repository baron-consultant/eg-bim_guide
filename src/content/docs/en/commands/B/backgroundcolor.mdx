- Changes the background color of the drawing.

![][image1]

## **1\. Changing the Background Color** [**Demo Video**](https://youtu.be/oZGhjNzGwpI)

1\) Type "BACKGROUNDCOLOR" in the Command Line.  
2\) Press the ENTER key.  
3\) The background color of the drawing changes.
