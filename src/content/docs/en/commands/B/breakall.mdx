- Breaks an object at all of its intersection points at once.

![][image1]

## **1\. Breaking an Object** [**Demo Video**](https://youtu.be/EkyQZYwNQlA)

1\) Run the "BREAKALL" command.  
2\) Select the intersecting objects (line, polyline, circle, arc, etc.).  
3\) The selected objects are all split at their intersection points.  
![][image2]
