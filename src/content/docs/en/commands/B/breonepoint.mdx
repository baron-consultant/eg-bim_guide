[image1]: ../../../../../assets/images/en/commands/breonepoint/image1.png

* Breaks the selected object (line, polyline, arc, etc.) at a single point, splitting it into two separate objects.

![][image1]

## **1\. Breaking an Object (Single-Point Based)** [**Demo Video**](https://youtu.be/JBw-Ms5tLIY)

1\) Type "BREONEPOINT" in the Command Line.  
2\) Select the object to break (line, polyline, arc, etc.).  
3\) Click the base point at which to break the object.  
4\) The object is split into two independent objects at the clicked point.
