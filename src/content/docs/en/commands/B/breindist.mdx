- Breaks the selected object by the entered distance.

![][image1]

## **1\. Breaking an Object** [**Demo Video**](https://youtu.be/EG7jhVRcUQU)

1\) Run the "BREINDIST" command.  
2\) Select an object (line, polyline, rectangle, etc.).  
3\) Select the start point and enter the break distance.
