- Breaks an object based on a point location specified on the object.

![][image1]

## **1\. Breaking an Object** [**Demo Video**](https://youtu.be/dNfgVvRVuho)

1\) Run the "BRESPOINT" command.  
2\) Select an object (line, polyline, rectangle, etc.).  
3\) Specify the point on the object at which to break it.  
4\) The selected object is divided at the specified point.  
![][image2]
