[image1]: ../../../../../assets/images/en/commands/breipoint/image1.png

* Breaks the selected object (line, polyline, arc, etc.) at a single base point, splitting it into two separate objects.

![][image1]

## **1\. Breaking an Object (Object-Based)** [**Demo Video**](https://youtu.be/W5O15QkB_sI)

1\) Type "BREIPOINT" in the Command Input Window.  
2\) Select the reference object to break at (line, polyline, arc, etc.).  
3\) Select the object to break.  
4\) The object is split into two independent objects based on the selected reference object.
