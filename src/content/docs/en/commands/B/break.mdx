- Cuts the selected object (line) by specifying two points.
- After cutting, the object is split into two separate objects.

![][image1]

## **1\. Breaking an Object** [**Demo Video**](https://youtu.be/EkyQZYwNQlA)

1\) Run the "BREAK" or "BR" command.  
2\) Select the object to cut (line, polyline, circle, arc, etc.).  
3\) Click the first base point. (the break start location)  
4\) Click the second base point. (the break end location)  
5\) The section between the two specified points is removed, and the object is split into two.  
![][image2]
