- Breaks an object based on a point location specified on the object.

![][image1]

## **1\. Breaking an Object** [**Demo Video**](https://youtu.be/uBROCy2oC4A)

1\) Run the "BRESDIST" command.  
2\) Type "S" to set the distance, spacing, etc. at which to break the object.  
3\) Select an object (line, polyline, rectangle, etc.).  
4\) Press ENTER or the Space bar.  
5\) The selected object is divided at equal intervals.
