- Specifies or changes the insertion base point of a block.
- When a block is inserted into a drawing, it is placed based on the specified insertion point, allowing precise position control.

![][image1]

## **1\. Changing the Block Insertion Base Point** [**Demo Video**](https://youtu.be/z_nWe2zza-k)

1\) Type "BINSERTIONPOINT" in the Command Line.  
2\) Select the block for which to specify the base point.  
3\) Click with the mouse or enter coordinate values to specify the new base point location.  
4\) Once specified, the block's insertion base point changes.
