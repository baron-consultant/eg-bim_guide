- Defines multiple objects drawn in the drawing as a single block so they can be reused later.

![][image1]

## **1\. Creating a Block** [**Demo Video**](https://youtu.be/VC_wqhMUENI)

1\) Run the "BLOCK" command in the Command Line.  
2\) Click the ADD button in the BLOCK dialog box.  
![][image2]  
3\) Select the desired block and specify the insertion location to place the block in the drawing.
