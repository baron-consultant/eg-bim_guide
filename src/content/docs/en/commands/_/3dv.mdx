- This command launches the 3D Viewer program, which lets you visually inspect the 3D model.

![][image1]

## **1\. Launching the 3D Viewer** [**Demo Video**]()

1\) Type "3DV" in the Command Input Window.  
2\) Press the ENTER key.  
3\) The EG-BIM Viewer program launches automatically.
