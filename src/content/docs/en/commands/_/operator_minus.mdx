- This function subtracts the values of text objects containing numbers in the drawing.

![][image1]

## **1\. Subtracting Numbers** [**Demo Video**](https://youtu.be/wC6DFMdDeCA)

1\) Type “\-” in the Command Input Window.  
2\) Following the Command Input Window prompts, select the text objects containing numbers in order.  
3\) When you finish selecting, press the ENTER key.  
4\) Click the point to insert, and the subtraction result is added to the drawing as text.
