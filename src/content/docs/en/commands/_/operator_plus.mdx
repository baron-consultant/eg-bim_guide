- This function adds the values of text objects containing numbers in the drawing.

![][image1]

## **1\. Adding Numbers** [**Demo Video**](https://youtu.be/hDDzAQAYNAY)

1\) Type "+" in the Command Line.  
2\) Following the Command Line prompts, select the text objects containing numbers in order.  
3\) When you finish selecting, press the ENTER key.  
4\) Click the point to insert, and the sum result is added to the drawing as text.
