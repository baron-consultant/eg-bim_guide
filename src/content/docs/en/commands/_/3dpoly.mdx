- Creates a 3D polyline.

![][image1]

- Option keywords for specifying the start point of the 3D polyline

- Follow or ENTER: Specify the last point as the start point of the 3D polyline
- Specify the point on screen with the mouse

![][image2]

## **1\. Drawing a 3D Polyline** [**Demo Video**](https://youtu.be/5gfnEL3CAHY)

1\) Run the "3DPOLY" command.  
2\) Click the mouse to specify the start point.  
3\) Click the mouse to specify the next point.  
4\) You can use the Undo option keyword.  
&nbsp;&nbsp;4-1) To use it, enter the Undo keyword to return to the previous point.  
5\) When you click the mouse for the third next point, you can use the Close keyword or the Undo keyword.  
&nbsp;&nbsp;5-1) If you use the Close keyword, the object is closed based on the initial start point. (This ends the command.)  
&nbsp;&nbsp;5-2) If you use the Undo keyword, it returns to the previous point.  
6\) Press the ESC key or the Space bar to end the command.

## **2\. Returning to the Previous Point While Drawing a 3D Polyline** [**Demo Video**](https://youtu.be/L_Sso4MRlwI)

1\) Run the "3DPOLY" command.  
2\) Click the mouse to specify the start point.  
3\) Click the mouse to specify the next point.  
4\) Enter the Undo keyword to return to the previous point.

## **3\. Closing the Object While Drawing a 3D Polyline** [**Demo Video**](https://youtu.be/hT9huG4RGHk)

1\) Run the "3DPOLY" command.  
2\) Click the mouse to specify the start point.  
3\) Click the mouse to specify the next point.  
4\) Enter the Close keyword to close the object based on the start point.
