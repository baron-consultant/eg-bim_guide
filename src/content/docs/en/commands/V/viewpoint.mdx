* A command that sets a 3D view by specifying a viewpoint, orienting the screen toward a specific direction (based on the X, Y, Z axes).

![][image1]

## **1\. Specifying a 3D Viewpoint** [**Demo Video**](https://youtu.be/T5x7aQDA3t8)

1\) Type "VIEWPOINT" in the Command Input Window.  
2\) Enter the viewpoint directly as coordinates, or use the rotation option.

| Option | Description |
| :---: | ----- |
| Perspective | Turns Perspective view on or off. Used to convey a sense of depth. |
| PLAN | Switches to a plan (top-down) view based on the current UCS. |
| Rotate | Rotates the viewpoint to observe the model from a different angle. |

3\) After entering the coordinates or option, press the ENTER key.  
4\) The screen switches to the specified 3D viewpoint.
