- Displays only objects of a specific color in the drawing, while temporarily hiding objects of other colors.

![][image1]

## **1\. Displaying Only Objects of a Specific Color** [**Demo Video**](https://youtu.be/npMNN-DDcQc)

1\) Run the "VIEWSELECTIONCOLOR" command.  
2\) The color selection dialog box appears.  
3\) Select the color of the objects to display in the drawing.  
4\) Press ENTER or the SPACE BAR to complete the selection.  
5\) Only objects with the selected color are displayed on screen, and objects of all other colors are hidden.  
Note: Running the "VIEWALLENTITIES" command displays all objects again.
