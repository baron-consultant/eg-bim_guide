[image1]: ../../../../../assets/images/en/commands/vports/image1.png

- Splits the current screen into multiple views, or creates and arranges viewports for use in paper space.

![][image1]

## **1\. Creating Viewports** [**Demo Video**](https://youtu.be/cNeCaf8bH9Q)

1\) Go to the Layout tab.  
2\) Type "VPORTS" in the Command Input Window.  
3\) The Viewports dialog box appears.  
4\) Select a screen division method (e.g., Single, Two, Three, Four, etc.).  
5\) Depending on the selected option, the screen is divided into multiple views, or a new viewport is created in paper space.
