* A command that clips the display area of a viewport in paper space, or defines its boundary as a specific shape (rectangle, polygon, etc.).

![][image1]

## **1\. Setting Up Viewport Clipping** [**Demo Video**]()

1\) Switch to the Layout tab.  
2\) Type "VPCLIP" in the Command Line.  
3\) Select the viewport to clip.  
4\) Specify the clipping option.

| Option | Description |
| :---: | ----- |
| Polygonal | Specifies a new polygonal boundary. |
| Delete | Deletes the existing clipping boundary and restores the original rectangular viewport. |

5\) Specify the boundary with the mouse, and the viewport is clipped to that shape.
