[image1]: ../../../../../assets/images/en/commands/vpmax/image1.png

- Maximizes the currently selected viewport, expanding it to fill the entire screen.

![][image1]

## **1\. Maximizing a Viewport** [**Demo Video**](https://youtu.be/2520Zpu2gyo)

1\) Go to the Layout tab.  
2\) Type "VPMAX" in the Command Line.  
3\) Press the ENTER key.  
4\) The selected viewport expands to fill the screen and becomes editable as if it were model space.  
Note: Type the "VPMIN" command to return to the previous state.
