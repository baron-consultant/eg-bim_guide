- Selects an object contained inside a block or Xref and copies it directly into the current drawing.

![][image1]

## **1\. Copying an Object Inside a Block** [**Demo Video**](https://youtu.be/TeSvy_izJBA)

1\) Run the "NCOPY" command in the Command Line.  
2\) When selecting an object, click the desired element inside a block or Xref.  
3\) The selected object is copied into the current drawing space.  
![][image2]
