- Automatically reads the coordinate values of point objects placed in the drawing and creates coordinate text at their locations.

![][image1]

## **1\. Creating Coordinates** [**Demo Video**](https://youtu.be/5MxNN6c_wbc)

1\) Type "POINTTOTEXT" in the Command Line.  
2\) Configure the required items in the dialog box.  
![][image2]  
2\) Select the point objects for which to display coordinates.  
3\) The command automatically calculates the coordinates (X, Y, Z) of each point.  
4\) Based on the calculated coordinate values, a text object is created near each point.
