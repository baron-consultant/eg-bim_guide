- Sets a specific layer to be displayed on screen while excluding it from printed output.

![][image1]

## **1\. Excluding a Layer from Printing** [**Demo Video**](https://youtu.be/EQI5AHv0H6I)

1\) Type "PLOTLAYOFF" in the Command Input Window.  
2\) Select an object (one belonging to the layer) to exclude from printing.  
3\) The layer that the object belongs to is changed to the plot-excluded state.  
4\) After this, running the "PLOT" command will not print the objects on that layer.
