title: PSLTSCALE

[image1]: ../../../../../assets/images/en/commands/psltscale/image1.png

- Sets whether linetype scale in paper space is adjusted to match the viewport scale.

![][image1]

## **1\. Adjusting Line Scale** [**Demo Video**](https://youtu.be/mskkS_KMaOc)

1\) Type "PSLTSCALE" in the Command Input Window.  
2\) Enter one of the following values.

- ON: Ignores viewport scale \- Uses each viewport's actual linetype spacing (LTSCALE) as-is
- OFF: Reflects viewport scale \- Displays the same line pattern spacing in all viewports (default)

3\) Press the ENTER key.  
4\) Type "REGEN" in the Command Input Window to refresh the screen.
