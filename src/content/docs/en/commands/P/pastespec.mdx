- Pastes data copied to the clipboard into the current drawing in a specific format (such as Bitmap or Script Text) that you select.

![][image1]

## **1\. Pasting an Object as a Block** [**Demo Video**](https://youtu.be/7TdH38sMsm0)

1\) Run the "PASTEBLOCK" command.  
Note: An object must already be copied to the clipboard using the COPYCLIP command.  
2\) A dialog box for selecting the paste format appears.  
2\) Specify the base point for pasting.  
3\) The copied object is automatically converted into a temporary block and pasted.  
![][image2]
