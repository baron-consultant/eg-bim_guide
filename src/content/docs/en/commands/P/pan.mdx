[image1]: ../../../../../assets/images/en/commands/pan/image1.png

- Pans the view without changing the drawing's display scale, moving only the visible portion on screen.

![][image1]

## **1\. Moving the Screen** [**Demo Video**](https://youtu.be/AnWVCMHGkeo)

1\) Type "ZOOM" in the Command Line.  
2\) Press the ENTER key.  
3\) The cursor changes to a hand shape; click and drag with the mouse to move the screen.  
4\) When you have finished moving, press Enter or ESC to end the command.  
Note: Pressing and dragging the mouse wheel immediately produces the same effect as the PAN command.
