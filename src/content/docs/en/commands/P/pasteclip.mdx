- Pastes an object copied to the clipboard into the current drawing.

![][image1]

## **1\. Pasting an Object** [**Demo Video**](https://youtu.be/ugFlsKW1OTo)

1\) Run the "PASTECLIP" command.  
Note: An object must already be stored on the clipboard using a previous COPYCLIP (copy) or CUTCLIP (cut) command  
before running this command.  
2\) Specify the base point for pasting.  
3\) The selected object is pasted into the current drawing.
