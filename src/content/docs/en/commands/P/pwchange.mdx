- Changes the line weight of the selected objects in a batch.

![][image1]

## **1\. Changing Object Line Weight** [**Demo Video**](https://youtu.be/YuyEVKOXsAo)

1\) Run the "PWC" or "PWCHANGE" command.  
2\) Select the objects (line, polyline, circle, rectangle, etc.) whose line weight you want to change.  
3\) Press ENTER to finish the selection.  
4\) Enter the desired lineweight value.  
5\) Press ENTER or the SPACE bar.  
6\) The line weight of the selected objects is changed in a batch to the entered value.
