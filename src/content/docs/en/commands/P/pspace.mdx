[image1]: ../../../../../assets/images/en/commands/pspace/image1.png

- Switches from the current model space (working space) to paper space (output space).

![][image1]

## **1\. Switching to Paper Space** [**Demo Video**](https://youtu.be/p2oe01KizMU)

1\) Move to the Layout tab.  
2\) Type "PSPACE" in the Command Line.  
3\) Press the ENTER key.  
4\) The current workspace switches to paper space.  
Note: To return from paper space to model space, use the "MSPACE" command.
