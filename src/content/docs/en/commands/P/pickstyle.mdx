[image1]: ../../../../../assets/images/en/commands/pickstyle/image1.png

- Controls whether groups and associative hatches can be selected as a single object in the drawing.

![][image1]

## **1\. Setting Object Selection** [**Demo Video**](https://youtu.be/zeKjQhPC5Ac)

1\) Type "PICKSTYLE" in the Command Input Window.  
2\) Enter the desired value.

- 0: Ignores groups and associative hatches → only individual objects are selected
- 1: Groups can be selected as a single object
- 2: Associative hatches can be selected as a single object
- 3: Both groups and associative hatches can be selected as a single object
