- Restores a layer whose printing was disabled by the "PLOTLAYOFF" command back to a printable state.

![][image1]

## **1\. Restoring Layer Printing** [**Demo Video**](https://youtu.be/xbZi8UKc1VE)

1\) Type "PLOTLAYON" in the Command Input Window.  
2\) Select an object (one belonging to the layer) to include in printing.  
3\) The layer that the object belongs to, whose printing had been turned off by the "PLOTLAYOFF" command, is changed to the plot-included state.
4\) After this, running the "PLOT" command will print the objects on that layer.
![][image2]
