- Creates or deletes a drawing (Layout), and renames or activates an existing layout.

![][image1]

## **1\. Managing Layouts** [**Demo Video**](https://youtu.be/ihhtyivq1kQ)

1\) Type "PAGESETUP" in the Command Input Window.  
2\) The PageSetup Manager window appears.  
![][image2]  
3\) Select the Add or Modify button.  
4\) Configure the print settings (printer, paper size, plot area, scale, style table, etc.).  
![][image3]  
5\) Click OK to save the settings.  
6\) Afterward, you can load and apply this setting from the Layout tab or the Plot window.
