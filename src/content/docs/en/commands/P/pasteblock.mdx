- Pastes an object copied to the clipboard into the current drawing as an anonymous block (temporary block).

![][image1]

## **1\. Pasting as a Block** [**Demo Video**](https://youtu.be/ZkKewLxQlpA)

1\) Select an object in the drawing and copy it to the clipboard using the COPYCLIP (Ctrl+C) or CUTCLIP (Ctrl+X) command.  
2\) Type "PASTEBLOCK" in the Command Line.  
3\) The object stored on the clipboard is inserted into the current drawing as an anonymous block.  
![][image2]
