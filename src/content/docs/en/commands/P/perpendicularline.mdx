- Automatically creates a line that intersects an object perpendicularly (at a right angle).

![][image1]

## **1\. Creating a Perpendicular Line** [**Demo Video**](https://youtu.be/Zxl_sm1AAU8)

1\) Type "PERPENDICULARLINE" in the Command Line.  
2\) Configure the required items in the dialog box.  
![][image2]  
3\) Select the object (circle or arc) on which to draw the perpendicular line.  
4\) Click the point where the perpendicular line will start.  
5\) Select the direction of the perpendicular line.  
6\) The perpendicular line is automatically created in the drawing according to the selected conditions.
