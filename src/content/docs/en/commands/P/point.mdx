- Draws a single point.

## **1\. Drawing a Point** [**Demo Video**](https://youtu.be/XJS6KbvBdAw)

1\) Run the POINT command.
2\) Click with the mouse in the drawing to draw a point.

## **2\. Drawing Multiple Points** [**Demo Video**](https://youtu.be/qNIwg00927o)

1\) Run the POINT command.  
2\) In the Command Input Window, select the Multiple option from the Settings/Multiple options.  
3\) Click with the mouse in the drawing to draw points; you can keep drawing until you end the command (by pressing SPACE).

![][image1]

## **3\. Changing the Point Style** [PTYPE](../p/ptype)

You can change the point style using the 'PTYPE' command.
