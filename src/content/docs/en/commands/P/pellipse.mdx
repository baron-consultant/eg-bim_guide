---
title: PELLIPSE
---

[image1]: ../../../../../assets/images/en/commands/pellipse/image1.png

- Sets whether ellipses are drawn as polylines.
- Setting ON \=\> The object type of ellipses drawn with the ELLIPSE command is polyline;  
Setting OFF \=\> The object type of ellipses drawn with the ELLIPSE command is ellipse.

![][image1]

## **1\. How to Turn the Setting On and Off** [**Demo Video**](https://youtu.be/6wocHQQTr0g)

1\) Run the "PELLIPSE" command.  
2\) To turn it ON, type ON or 1 in the Command Input Window;  
to turn it OFF, type OFF or 0 in the Command Input Window.
