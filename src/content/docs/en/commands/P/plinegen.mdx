---
title: PLINEGEN
---

[image1]: ../../../../../assets/images/en/commands/plinegen/image1.png

- Sets whether the line style is applied at each vertex of the polyline.
- Setting ON \=\> The current line style is applied at each vertex of polylines drawn with the PLINE command,  
Setting OFF \=\> The current line style starts only at the start point of polylines drawn with the PLINE command and continues uninterrupted through the vertices, (applied continuously)

![][image1]

## **1\. How to Turn the Setting On and Off** [**Demo Video**](https://youtu.be/wL3qiCXVaek)

1\) Run the "PLINEGEN" command.  
2\) To turn it ON, type ON or 1 in the Command Input Window;  
to turn it OFF, type OFF or 0 in the Command Input Window.
