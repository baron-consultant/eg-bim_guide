* Automatically creates spacers.

![][image1]

## **1\. Creating Spacers** [**Demo Video**]()

1\) Type "PREFABRICATEDBAR" in the Command Input Window.  
2\) Following the Command Input Window prompts, select points.

- First point: the spacer's start point  
- Second point: the spacer's end point

3\) Spacers are created along the selected line.
