- Changes the layer of a selected object in the drawing to match the layer of another object.

![][image1]

## **1\. Change Layer to Match Another Object** [**Demo Video**](https://youtu.be/ePoPimAk9JY)

1\) Type the "LAYMCH" command in the Command Line.  
2\) Select the target object whose layer you want to change.  
3\) Select the reference object to match.  
4\) The target object's layer is changed to match the reference object's layer.  
![][image2]
