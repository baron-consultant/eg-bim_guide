- A command that sets or changes the length unit format of the drawing.

![][image1]

## **1\. Changing the Length Unit** [**Demo Video**](https://youtu.be/xnmdIWy-gYk)

1\) Type "LUNITS" in the Command Line.  
2\) Select a numeric option in the Command Line.

| Option No. |      Unit Format      | Description                                    |
| :-------: | :-----------------: | ---------------------------------------------- |
|     1     |  Scientific   | Displayed as a power of 10 (e.g., 1.23E+03)           |
|     2     |    Decimal    | Standard decimal number format (e.g., 123.4567)              |
|     3     |  Engineering  | Displayed in feet and inches (e.g., 12'-6.50\")          |
|     4     | Architectural | Displayed in feet, inches, and fractions (e.g., 12'-6 1/2\") |
|     5     |  Fractional   | Displayed as a fraction (e.g., 6 1/2)                   |

3\) Press the ENTER key to apply the setting.
