- Controls how faded (the fade effect) objects on a locked layer appear on screen.

![][image1]

## **1\. Adjust Locked Layer Fade** [**Demo Video**](https://youtu.be/iUv0G6o931k)

1\) Type the "LAYLOCKFADECTL" command in the Command Line.  
2\) You can check the currently configured value.

- The default value is usually set to 50 (50% fade).

3\) Enter the desired value.

- 0 : No fade effect (locked objects are displayed the same as normal)
- 1 \~ 90 : The higher the number, the more faded the objects appear

4\) Press ENTER or the SPACE BAR to apply the setting.
