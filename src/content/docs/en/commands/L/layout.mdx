- A function that creates or deletes a drawing (Layout), and renames or activates an existing layout.

![][image1]

## **1\. Managing Layouts** [**Demo Video**](https://youtu.be/G_gSQrYYPk8)

1\) Type "LAYOUT" in the Command Line.  
2\) Select one of the options below.

|   Option   | Description                                                             |
| :------: | ---------------------------------------------------------------- |
|   New    | Creates a new layout. A new drawing tab is automatically added.  |
|  Delete  | Deletes the selected layout. (The currently active layout cannot be deleted.)   |
|  Rename  | Renames the selected layout.                             |
| Template | Imports a layout from another drawing file (DWT, DWG).                |
|   Copy   | Duplicates the selected layout to create a new layout with identical settings. |
|   Move   | Changes the tab order of the selected layout.                          |
|   Save   | Saves the current layout as a separate file.                        |
|   Set    | Activates the specified layout.                      |

3\) Perform the desired operation (create a new layout, delete, copy, etc.).
