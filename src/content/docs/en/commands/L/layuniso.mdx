title: LAYUNISO
---

[image1]: ../../../../../assets/images/en/commands/layuniso/image1.png

- A function that restores the remaining layers, which were hidden or locked while only the layer selected with the LAYISO command was displayed, back to their original state.

![][image1]

## **1\. Restoring Layers** [**Demo Video**](https://youtu.be/riwt-5s62cA)

1\) Type "LAYUNISO" in the Command Line.  
2\) Press the ENTER key.  
2\) The display/lock state of all layers is restored to the state before LAYISO was run. (Layers that were hidden are displayed again, and layers that were locked are unlocked again.)
