title: LAYTHW
---

[image1]: ../../../../../assets/images/en/commands/laythw/image1.png

- A command that unfreezes all frozen layers in the drawing at once.

![][image1]

## **1\. Unfreezing Layers** [**Demo Video**](https://youtu.be/x_Q0WRQMtbc)

1\) Type "LAYTHW" in the Command Line.  
2\) Press the ENTER key.  
3\) All frozen layers in the drawing are unfrozen, and the objects that were hidden reappear on the screen.
