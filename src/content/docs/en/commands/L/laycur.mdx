- Changes the layer of a selected object in the current drawing to the current layer.

![][image1]

## **1\. Change to Current Layer** [**Demo Video**](https://youtu.be/Px0IstllWCw)

1\) Type the "LAYCUR" command in the Command Line.  
2\) Select the desired object in the drawing.  
3\) The layer that the selected object belongs to is set as the current layer.  
![][image2]
