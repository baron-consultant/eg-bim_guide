title: LTSCALE
---

[image1]: ../../../../../assets/images/en/commands/ltscale/image1.png

- Changes the scale ratio of the line scale.
- You can check the currently applied line scale ratio using the value inside "\< \>" that appears when you run the command.

![][image1]

## **1\. How to Change the Line Scale Ratio** [**Demo Video**](https://youtu.be/wxjwjBp7rcQ)

1\) Run the "LTSCALE" command.  
2\) Enter the desired scale ratio and press ENTER.  
3\) You can confirm that the change was applied by re-running "LTSCALE" and checking the current line scale ratio inside "\< \>".
