- A command that adjusts the length or angle of a selected object (line, arc, polyline, etc.).

![][image1]

## **1\. Adjusting Object Length**

1\) Run the "LENGTHEN" command.  
2\) Select one of the following options.

- Dynamic [**Dynamic Length Adjustment Demo Video**](https://youtu.be/9opeeW_JLE8)

Directly grab the endpoint of the object with the mouse to lengthen or shorten it. You can see the length change in real time.

- Increment [**Increment Length Adjustment Demo Video**](https://youtu.be/MzdU_kb3G1w)

Lengthens or shortens the object by adding or subtracting a fixed value to/from its current length.  
Example: \+50 `→` extends the current length by 50 units / -20 `→` reduces the current length by 20 units.

  <br />

- Percent [**Percent Length Adjustment Demo Video**](https://youtu.be/8R4ETkkrTB0)

Lengthens or shortens the object by a percentage of its total length.  
Example: 120% `→` increases the total length by 20% / 50% `→` reduces the total length by half.

- Total (Specify Total Length) [**Total Length Adjustment Demo Video**](https://youtu.be/LdbChAlEW68)

Directly enter the desired final length.  
Example: Entering 1000 sets the object's length to 1000.

3\) Select the object.  
4\) The length is adjusted according to the entered option.  
5\) Press ENTER or the SPACE BAR to end the command.
