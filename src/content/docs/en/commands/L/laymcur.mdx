- Sets the layer of a selected object in the drawing as the current layer.

![][image1]

## **1\. Set as Current Layer** [**Demo Video**](https://youtu.be/Px0IstllWCw)

1\) Type the "LAYER" command in the Command Input Window.  
2\) Select the object whose layer you want to set as the current layer.  
3\) Press ENTER, and the layer of the selected object becomes the current layer.  
4\) All new objects created afterward will be created on the specified layer.  
![][image2]
