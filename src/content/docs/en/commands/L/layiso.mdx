- Displays (isolates) only the layer that a selected object belongs to, while turning off or locking all other layers, making it easy to work exclusively on the selected layer.

![][image1]

## **1\. Isolate a Single Layer** [**Demo Video**](https://youtu.be/N3kK31lIpEQ)

1\) Type the "LAYISO" command in the Command Input Window.  
2\) Select the object (or objects) whose layer you want to isolate on screen.  
3\) Press the ENTER key.  
4\) Only the layer of the selected object is displayed on screen; all other layers are turned off or locked.  
Note: Run the "LAYUNISO" command to release the isolated state.  
![][image2]
