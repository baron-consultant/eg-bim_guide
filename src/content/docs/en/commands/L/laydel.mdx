- Completely deletes a selected layer and all objects belonging to that layer from the drawing.

![][image1]

## **1\. Delete a Layer** [**Demo Video**](https://youtu.be/xqOds1IbYhE)

1\) Type the "LAYDEL" command in the Command Input Window.  
2\) Select the layer to delete. (You can click an object or specify a layer name.)  
3\) The layer and all objects it contains are deleted from the drawing.  
![][image2]
