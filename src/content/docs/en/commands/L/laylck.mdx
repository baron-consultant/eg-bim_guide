- Locks the layer that a selected object belongs to in the drawing. Objects on a locked layer are still displayed on screen but cannot be edited (moved, modified, deleted, etc.).

![][image1]

## **1\. Lock a Layer** [**Demo Video**](https://youtu.be/KZ9vxsRG2Z4)

1\) Type the "LAYLCK" command in the Command Input Window.  
2\) Select the object in the drawing whose layer you want to lock.  
3\) The layer that the object belongs to is automatically locked.  
Note: Objects on a locked layer are displayed faded (with transparency applied) and cannot be edited.  
![][image2]
