- A function that displays the basic properties and geometric information (length, area, coordinates, etc.) of the selected object in detail in the Command Line.

![][image1]

## **1\. Checking Object Properties** [**Demo Video**](https://youtu.be/jrckixd_Z2g)

1\) Type "LIST" in the Command Line.  
2\) Select the object whose properties you want to check.  
3\) Press the ENTER key.  
4\) The detailed information of the selected object is displayed in the Command Line.  
![][image2]
