title: LAYON
---

[image1]: ../../../../../assets/images/en/commands/layon/image1.png

- A function that turns on all layers that are off in the drawing, so that hidden objects are displayed on the screen again.

![][image1]

## **1\. Turning On Layers** [**Demo Video**](https://youtu.be/neUDibM_WCw)

1\) Type "LAYON" in the Command Line.  
2\) Press the ENTER key.  
3\) All layers that were off in the current drawing are turned on again.
