- Turns off the layer that a selected object belongs to in the drawing, hiding all objects on that layer from the screen.

![][image1]

## **1\. Turn Off a Layer** [**Demo Video**](https://youtu.be/K-oUSkzjzU8)

1\) Type "LAYOFF" in the Command Input Window.  
2\) Select an object that belongs to the layer you want to turn off.  
3\) Press the ENTER key to turn off the entire layer that the selected object belongs to.  
Note: All objects belonging to that layer will be hidden from the screen.  
![][image2]
