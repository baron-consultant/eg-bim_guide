---
title: LAYULK
---

[image1]: ../../../../../assets/images/en/commands/layulk/image1.png

- A function that unlocks locked layers. It restores a layer that was locked and uneditable via the LAYLCK command back to a normal, editable state.

![][image1]

## **1\. Unlocking Layers** [**Demo Video**](https://youtu.be/vsJ9qmAPLhE)

1\) Type "LAYULK" in the Command Line.  
2\) Select the object on the layer you want to unlock.  
3\) The layer that the selected object belongs to is unlocked.
