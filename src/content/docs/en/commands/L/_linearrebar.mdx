[image1]: ../../../../../assets/images/en/commands/linearrebar/image1.png

* A function that automatically places point rebars at regular intervals along a line or polyline.

![][image1]

## **1\. Create Line Point Rebars** [**Demo Video**](https://youtu.be/nfpuAG-KLTA)

1\) Type "LINEARREBAR" in the Command Line.  
2\) Following the Command Line prompts, select the points. 

- First point: Point rebar start location  
- Second point: Point rebar end location

3\) Point rebars are created along the selected line.
