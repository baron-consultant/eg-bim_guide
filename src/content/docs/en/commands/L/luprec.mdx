[image1]: ../../../../../assets/images/en/commands/luprec/image1.png

- A command that sets the number of decimal places for length (distance) units in the drawing.

![][image1]

## **1\. Setting the Length Decimal Places** [**Demo Video**](https://youtu.be/Zk6XaZ8jta4)

1\) Type "LUPREC" in the Command Input Window.  
2\) Following the prompt shown in the Command Input Window, enter a number between 0 and 8.  
Example: 4 → Displays up to 4 decimal places  
3\) Press the ENTER key to apply the setting.
