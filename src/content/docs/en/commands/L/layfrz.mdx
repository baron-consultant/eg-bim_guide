---
title: LAYFRZ
---

[image1]: ../../../../../assets/images/en/commands/layfrz/image1.png

- Freezes the layer that a selected object belongs to, hiding it from the screen. In other words, the entire layer containing the selected object is temporarily "frozen": all objects on that layer disappear from the screen and are excluded from CAD's performance calculations.

![][image1]

## **1\. Freeze a Layer** [**Demo Video**](https://youtu.be/RRkoYaJR2p0)

1\) Type the "LAYFRZ" command in the Command Input Window.  
2\) Select the object to freeze.  
3\) Press the ENTER key.  
4\) The layer that the selected object belongs to is frozen, and all objects on that layer disappear from the screen.
