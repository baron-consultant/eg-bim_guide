---
title: LAYERP
---

[image1]: ../../../../../assets/images/en/commands/layerp/image1.png

- Restores the layer state to what it was immediately before the last layer setting change. In other words, it restores the layer properties as they were right before the most recent change.

![][image1]

## **1\. Restore the Previous Layer State** [**Demo Video**](https://youtu.be/83pywJK04h0)

1\) Type the "LAYERP" command in the Command Line.  
2\) Press ENTER to restore the layer state to what it was before the last change.
