- Creates, manages, and edits the layers used in the drawing. Layers let you systematically manage object properties (color, linetype, lineweight, plot status, etc.), improving the efficiency and readability of drawing work.

![][image1]

## **1\. Manage Layers** [**Demo Video**](https://youtu.be/BW0sKXFYbug)

1\) Type the "LAYER" command in the Command Line.  
2\) The Layer Properties Manager dialog box appears.  
![][image2]  
3\) You can perform the following tasks.

- Create a new layer
- Delete a layer
- Rename a layer
- Set the layer color, linetype, and lineweight
- Set layer On/Off, Freeze/Thaw, Lock/Unlock
- Set plot status

4\) When you finish configuring the settings and close the dialog box, the changes are applied to the drawing.
