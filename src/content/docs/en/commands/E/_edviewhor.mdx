- Specifies two points to rotate and align the view in the horizontal direction.

![][image1]

## **1\. Setting the View to Horizontal** [**Demo Video**]()

1\) Type "EDVIEWHOR" in the Command Line.  
2\) Following the Command Line prompts, specify the two points in order.

- First point: specify the rotation reference start point
- Second point: specify the rotation reference end point

3\) Press the ENTER key.  
4\) The view rotates automatically, aligning the line connecting the two specified points with the horizontal direction of the screen.
