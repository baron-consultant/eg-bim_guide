* A command that extends or shortens (breaks) a leader line to align with a reference object.

![][image1]

## **1\. Extending / Shortening a Leader Line** [**Demo Video**](https://youtu.be/Kf3EJdRoLGA)

1\) Type "EXLEADERS" in the Command Line.  
2\) Select the reference object.  
3\) Select the leader line to extend or shorten.  
4\) Press the ENTER key.  
5\) The leader line is automatically extended or shortened based on the selected object.
