* A function that explodes a rebar marking block, converting each component (text, lines, symbols, etc.) into an individual object.

![][image1]

## **1\. Exploding a Rebar Marking** [**Demo Video**](https://youtu.be/rh1oiTl1PqM)

1\) Type "EXPLODEBEAMMARK" in the Command Line.  
2\) Following the Command Line prompts, select the rebar marking block to explode.  
Example: PMARK, SMARK, MMARK, CTCMARK, etc.  
3\) Press the ENTER key.  
4\) The selected block is automatically exploded, and each component is converted into an individual object.
