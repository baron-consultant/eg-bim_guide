- A function that deletes the selected object from the drawing.

![][image1]

## **1\. Deleting an Object** [**Demo Video**](https://youtu.be/PefIXL8dNfE)

1\) Run the "ERASE" or "E" command.  
2\) Select the objects to delete (lines, polylines, circles, blocks, hatches, images, etc.).  
3\) Press ENTER to complete the selection.  
4\) The selected objects are deleted from the drawing.
