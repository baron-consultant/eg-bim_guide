- A command that extends objects such as lines, polylines, and arcs to a selected boundary object.

![][image1]

## **1\. Extending an Object** [**Demo Video**](https://youtu.be/_h69H1EF1N4)

1\) Run the "EXTEND" command.  
2\) Select the boundary object (target line) to extend to.  
3\) Press ENTER.  
4\) Click the object to extend, and it is automatically extended to the boundary line.  
5\) Press ENTER or the SPACE BAR to end the command.
