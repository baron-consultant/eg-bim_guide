- A function that explodes an object composed of blocks, hatches, dimensions, etc. into individual elements.

![][image1]

## **1\. Exploding an Object** [**Demo Video**](https://youtu.be/7-tj-Z0kQM8)

1\) Run the "EXPLODE" or "X" command.  
2\) Select the objects to explode (blocks, polylines, hatches, dimensions, etc.).  
3\) Press ENTER to complete the selection.  
4\) The selected objects are exploded into their individual components.
