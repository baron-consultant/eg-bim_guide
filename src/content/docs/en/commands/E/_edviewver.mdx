- Specifies two points to rotate and align the view in the vertical direction.

![][image1]

## **1\. Setting the View to Vertical** [**Demo Video**]()

1\) Type "EDVIEWVOR" in the Command Input Window.  
2\) Following the Command Input Window prompts, specify the two points in order.

- First point: specify the rotation reference start point
- Second point: specify the rotation reference end point

3\) Press the ENTER key.  
4\) The view rotates automatically, aligning the line connecting the two specified points with the vertical direction of the screen.  
![][image2]
