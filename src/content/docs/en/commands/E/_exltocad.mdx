- Inserts Excel data into a CAD drawing as a table or text, or synchronizes an existing table in the drawing with an Excel file bidirectionally.

![][image1]

## **1\. Inserting Excel Data into CAD** [**Demo Video**]()

1\) Run the "EXLTOCAD" command.  
2\) Select the desired options in the EXLTOCAD dialog box.  
![][image2]  
3\) Set the display options such as text height, width, character spacing, and cell height/width.  
4\) Click OK to insert the selected Excel data into the CAD drawing.
