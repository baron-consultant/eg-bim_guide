- Trims the line segments outside a selected reference object.

![][image1]

## **1\. Trimming Outside an Object** [**Demo Video**](https://youtu.be/_h69H1EF1N4)

1\) Run the "EXTENDTRIM" command.  
2\) Select the reference object.  
3\) Enter the coordinates of the location to insert.  
4\) Press ENTER or the SPACE BAR to end the command.
