---
title: ELLIPSE
---

[image1]: ../../../../../assets/images/en/commands/ellipse/image1.png

- Creates an ellipse.
- You can create a new ellipse or an arc that is part of an ellipse.

![][image1]

- Ellipse drawing option keywords

* Arc: Draws an ellipse, then draws an arc by specifying the portion of the ellipse to keep.
* Center: Creates an ellipse by specifying the center point and an endpoint.

## **1\. Drawing an Ellipse** [**Demo Video**](https://youtu.be/f6rgRr0UNm0)

1\) Run the "ELLIPSE" command.  
2\) Specify the two endpoints of the ellipse axis with the mouse on the screen.  
3\) Specify the length of the minor axis to create the ellipse. (2 methods)  
&nbsp;&nbsp;&nbsp;&nbsp;3-1) Specify the Other Axis on screen with the mouse.  
&nbsp;&nbsp;&nbsp;&nbsp;3-2) Enter the Rotation keyword to specify the rotation around the major axis.

## **2\. Drawing an Arc Derived from an Ellipse** [**Demo Video**](https://youtu.be/lPmSvW-35bQ)

1\) Run the "ELLIPSE" command.  
2\) Enter the Arc keyword.  
3\) Specify both endpoints of the ellipse axis.  
4\) Specify the Other Axis on screen with the mouse.  
5\) Specify the portion to keep, and the arc is drawn. (2 methods)  
&nbsp;&nbsp;&nbsp;&nbsp;5-1) Specify the start angle and end angle of the arc on screen with the mouse.  
&nbsp;&nbsp;&nbsp;&nbsp;5-2) Enter the Parameter keyword to input the start and end parameters.  
&nbsp;&nbsp;&nbsp;&nbsp;5-3) After entering the start angle or start parameter, enter the Included keyword and input the included angle.
