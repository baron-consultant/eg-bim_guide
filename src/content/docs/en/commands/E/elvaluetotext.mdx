- A command that automatically creates a Text and Point pair in the drawing.

![][image1]

## **1\. Writing EL Values to an Object** [**Demo Video**](https://youtu.be/j-s6OboTwNA)

1\) Type "ELVALUETOTEXT" in the Command Line.  
2\) Configure the required items in the dialog box.  
![][image2]  
3\) The Z coordinate value of the selected object is automatically read.  
4\) An EL text is created at that location (or the configured offset location).
