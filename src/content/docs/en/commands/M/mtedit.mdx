* Modifies (edits) multiline text (Mtext) in the drawing.

![][image1]

## **1\. Editing Text Content** [**Demo Video**](https://youtu.be/mp9YTDQ2ApI)

1\) Type "MTEDIT" in the Command Input Window.  
2\) Select the multiline text to edit.  
3\) The In-Place Text Editor opens.  
4\) Modify the text content, or change the font, size, alignment, color, and so on.  
5\) Once editing is complete, click outside the editor or press the ESC key to exit.
