* Lets you apply continuous dimensions to multiple objects (lines, circles, arcs, etc.) all at once.

![][image1]

## **1\. Adding Continuous Dimensions to Multiple Objects** [**Demo Video**](https://youtu.be/GWc3Y6mVA58)

1\) Type "MULTIPLEDIM" in the Command Line.  
2\) Select the objects to dimension (lines, circles, arcs, etc.) in order.  
3\) Once selection is complete, specify the base line or dimension line location.  
4\) Continuous dimensions are automatically created for each selected object.
