- Batch-changes the layer properties of the selected objects. Even if multiple objects are on different layers, you can unify them to a specified layer's properties.

![][image1]

## **1\. Changing Layer Properties** [**Demo Video**](https://youtu.be/ntgqlku5GDs)

1\) Type the "MOLAYPROP" command in the Command Line.  
2\) Select the objects whose properties you want to change.  
3\) In the MOLAYPROP dialog box, specify the layer properties to change.  
![][image2]  
4\) Click the OK button, and the layer properties of the selected objects change to the specified values.
