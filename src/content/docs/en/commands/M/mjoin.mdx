* Automatically generates connecting lines at the clicked points to join separate lines, polylines, arcs, and so on into a single continuous polyline.

![][image1]

## **1\. Joining Polylines** [**Demo Video**](https://youtu.be/wqUvrKj3fX0)

1\) Type "MJOIN" in the Command Line.  
2\) Select the objects to join (lines, arcs, polylines, etc.).  
3\) If two lines are not directly connected, following the Command Line prompts, click the gap between them.  
4\) A connecting line is automatically generated at the clicked point.  
5\) The selected objects and the new connecting lines are merged into a single polyline.
