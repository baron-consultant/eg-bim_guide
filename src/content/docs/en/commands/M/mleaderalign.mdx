* Aligns multiple multileader objects horizontally or vertically.

![][image1]

## **1\. Aligning Leaders** [**Demo Video**](https://youtu.be/jWqv0hWnOq8)

1\) Type "MLEADERALIGN" in the Command Input Window.  
2\) Select multiple multileader (MLEADER) objects to align.  
3\) Press the ENTER key.  
4\) The following options are displayed in the Command Input Window.

| Option Name | Summary | Description |
| :---: | :---: | :---: |
| Distribute | Even distribution | Automatically aligns the selected leader text at equal intervals |
| make leader segments Parallel | Parallel leader lines | Aligns all leader lines to the same angle |
| specify Spacing | Manual spacing | Lets you manually set the spacing between leaders |
| Use current spacing | Keep current spacing | Aligns to the baseline while keeping the existing spacing |

5\) Select the desired alignment method.  
6\) Click the reference leader with the mouse, or specify the alignment direction on screen.  
7\) All selected leader text is automatically aligned according to the specified reference.
