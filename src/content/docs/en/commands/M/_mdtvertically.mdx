* A function that automatically aligns dimensions in the vertical direction.

![][image1]

## **1\. Aligning Dimensions Vertically** [**Demo Video**]()

1\) Type "MDTVERTICALLY" in the Command Input Window.  
2\) Select the dimension objects to align.  
3\) Press the Enter key when selection is complete.  
4\) All selected dimensions are automatically aligned vertically along the reference.
