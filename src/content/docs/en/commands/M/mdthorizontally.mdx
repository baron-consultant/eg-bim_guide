* A function that automatically aligns multiple dimensions in the horizontal direction.

![][image1]

## **1\. Aligning Dimensions Horizontally** [**Demo Video**](https://youtu.be/vmhyIscquy4)

1\) Type "MDTHORIZONTALLY" in the Command Line.  
2\) Select the dimension objects to align.  
3\) Press the Enter key when selection is complete.  
4\) Following the Command Line prompts, click the reference dimension or reference line.  
5\) All selected dimensions are automatically aligned horizontally along the reference line.
