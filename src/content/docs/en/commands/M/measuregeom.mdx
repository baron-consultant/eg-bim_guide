- A command that measures geometric information such as distance, radius, angle, and area in the drawing.

![][image1]

## **1\. Measuring Geometric Information** [**Demo Video**](https://youtu.be/cw34hhP6bBU)

1\) Type "MEASUREGEOM" in the Command Input Window.  
2\) Select one of the options below.

- Distance / Radius / Angle / Area

3\) Specify the point or object to measure.  
4\) The measurement result is displayed in the Command Input Window and in a tooltip near the cursor.  
![][image2]
