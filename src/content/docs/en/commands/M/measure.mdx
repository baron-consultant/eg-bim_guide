- A function that explodes an object composed of blocks, hatches, dimensions, etc. into individual elements.

![][image1]

## **1\. Dividing an Object at Equal Intervals** [**Demo Video**](https://youtu.be/TmEdjO4OWQ0)

1\) Run the "MEASURE" command.  
2\) Select the object (line, polyline, circle, arc, etc.) to divide into intervals.  
3\) Press ENTER to complete the selection.  
4\) Enter the interval. (e.g., 10 → points are placed along the object at 10-unit intervals)  
5\) Press ENTER or the SPACE BAR.  
6\) Points or blocks are automatically placed along the object according to the specified interval.
