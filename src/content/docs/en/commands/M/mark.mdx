- A function that inserts a rebar marking at the clicked point.

![][image1]

## **1\. Creating a Rebar Mark** [**Demo Video**](https://youtu.be/y3piunbRjos)

1\) Type "MARK" in the Command Input Window.  
2\) Following the Command Input Window prompts, click the location where you want to insert the rebar mark.  
3\) The default rebar mark block is automatically created at that location.
