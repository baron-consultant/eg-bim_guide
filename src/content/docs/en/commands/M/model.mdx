- Switches from Layout (paper space) to Model Space.

![][image1]

## **1\. Switching to Model Space** [**Demo Video**](https://youtu.be/sbT_PBSHJ4A)

1\) Go to the Layout tab.  
2\) Type the "MODEL" command in the Command Line.  
3\) Press the ENTER key.  
4\) The workspace switches from paper space to model space.
