* Measures and marks the slope of an object or between two points.

## **1\. Displaying the Slope of an Object** [**Demo Video**](https://youtu.be/zdwdscxsMdg)

1\) Type "MARKSLOPETEXT" in the Command Input Window.  
![][image1]  
2\) In the popup window, set the application method, slope display format, slope text size, etc., and click 'OK'.  
![][image2]  
3\) Click the object whose slope you want to measure in the drawing, and press the Enter key.  
![][image3]  
![][image4]  
![][image5]

## **2\. Displaying the Slope Between Two Points** [**Demo Video**](https://youtu.be/HLkCjnMv2bM)

1\) Type "MARKSLOPETEXT" in the Command Input Window.  
![][image6]  
2\) In the popup window, set the application method, slope display format, slope text size, etc., and click 'OK'.  
![][image7]  
3\) Select the two points whose slope you want to measure in the drawing.
