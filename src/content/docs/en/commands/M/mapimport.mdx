* A command that imports external GIS (Geographic Information System) data files into the drawing.

![][image1]

## **1\. Importing an External GIS File** [**Demo Video**](https://youtu.be/4Bbm5poAEGg)

1\) Type "MAPIMPORT" in the Command Line.  
2\) Select the GIS data file (SHP, SDF, SQLite, etc.) to import.  
3\) Select the desired file in the dialog box.  
![][image2]  
4\) Click "OK" to import the data into the drawing.
