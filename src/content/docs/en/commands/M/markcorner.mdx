* A command that automatically creates chevron lane markings for roads in the drawing.

![][image1]

## **1\. Creating Chevron Lane Markings** [**Demo Video**](https://youtu.be/oO73ZkiawbE)

1\) Type "MARKCORNER" in the Command Input Window.  
2\) Select the first lane.  
3\) Select the second lane.  
4\) Select the reference method for the chevron markings.

- P (Two Points): Manually specify two points to determine the direction.  
- L (Line Object): Automatically recognize the direction based on a specific line.

5\) Following the Command Input Window prompts, specify the start point and endpoint of the road marking in order.
