* A function that moves dimension text outside the object in a batch.

![][image1]

## **1\. Moving Dimensions Outside the Object** [**Demo Video**](https://youtu.be/qESeuVOXj_Y)

1\) Type "MDTOUTSIDE" in the Command Input Window.  
2\) Select the dimension objects whose dimension text you want to move.  
3\) Press the Enter key when selection is complete.  
4\) All selected dimension text is automatically moved outside the object.
