- A function that creates a mirrored copy of the selected object based on a specified mirror plane in 3D space.

![][image1]

## **1\. 2D Mirror Copy of an Object** [**Demo Video**](https://youtu.be/1KQuSU1tIhI)

1\) Run the "MIRROR" or "MI" command.  
2\) Select the object (line, polyline, circle, rectangle, etc.) to mirror.  
3\) Press ENTER to complete the selection.  
4\) Specify the first point to define the mirror line.  
5\) Specify the second point to define the mirror line.  
6\) Choose whether to keep the original object.

- Yes → Delete the original object, leaving only the mirrored object
- No → Keep the original object \+ create a mirrored copy

7\) Press the ENTER key or the Space bar.  
8\) The selected object is mirrored about the specified axis.
