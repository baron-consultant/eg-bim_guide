#### Command Options

![][image1]

- Load style \> Loads an .mln file to import a style.

- Justification \> Sets the justification to Top, Zero, or Bottom.  
  ![][image2]
- Scale \> Sets the scale value.  
  ![][image3]
- STyle \> Lets you check or set the MLINE style name.  
  ![][image4]
  ![][image5]

## **1\. How to Draw Multiple Parallel Lines**

1\) Click to specify the Start Point, then click to specify the Next Point.  
2\) Continue clicking Next Point at the desired locations, and once all lines are drawn, press the Space bar or ENTER.

<br />
&nbsp;&nbsp;&nbsp;&nbsp;-> While clicking Next Point at the desired locations, you can use the \[Close/Undo\] option.
<br />
&nbsp;&nbsp;&nbsp;&nbsp;2-1) If you click or type Close in the Command Input Window, it closes based on the Start Point.  
&nbsp;&nbsp;&nbsp;&nbsp;2-2) If you click or type Undo in the Command Input Window, it returns to just before the last Next Point was drawn.  
&nbsp;&nbsp;&nbsp;&nbsp;2-3) While clicking Next Point at the desired locations, press the ESC key if you want to cancel everything.
