* A command that calculates the volume of a 3D solid or the area of a 2D region.

![][image1]

## **1\. Calculating Object Volume** [**Demo Video**](https://youtu.be/OmcC9-Wmhhs)

1\) Type "MASSPROP" in the Command Line.  
2\) Select the object (3D solid or 2D region) whose properties you want to calculate.  
3\) Press the Enter key.  
4\) The volume calculation result for the object is displayed in the Command Line.
