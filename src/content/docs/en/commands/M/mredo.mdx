* A command that redoes multiple undo steps at once.

![][image1]

## **1\. Restoring Multiple Steps** [**Demo Video**](https://youtu.be/uVnf_JeDiwY)

1\) Type "MREDO" in the Command Input Window.  
2\) Following the prompt, enter the number of steps to redo.  
3\) The previously undone operations are restored at once, up to the number entered.
