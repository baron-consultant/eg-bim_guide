* Edits an existing multileader object, letting you add or remove leader lines.

![][image1]

## **1\. Editing a Leader** [**Demo Video**](https://youtu.be/jjQmN8rbpU0)

1\) Type "MLEADEREDIT" in the Command Line.  
2\) Click the multileader (MLEADER) object to edit.  
3\) The following options are displayed.

| Option | Description |
| :---: | :---: |
| Add Leader (A) | Adds a new leader line. |
| Remove Leader (R) | Removes an existing leader line. |

4\) Enter the desired option and click the leader line to add or remove it.
