[image1]: ../../../../../assets/images/en/commands/mspace/image1.png

- Switches from the paper space (for output) you are currently working in to model space (for drafting).

![][image1]

## **1\. Switching to Model Space** [**Demo Video**](https://youtu.be/WJ9v0BNY-rs)

1\) Go to the Layout tab.  
2\) Type the "MSPACE" command in the Command Input Window.  
3\) Press the ENTER key.  
4\) The current workspace switches to model space.  
Note: To return to paper space, use the "PSPACE" command.
