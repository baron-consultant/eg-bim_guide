* Creates, edits, and manages multileader styles.

![][image1]

## **1\. Managing Styles** [**Demo Video**](https://youtu.be/TgzLzwNzXus)

1\) Type "MLEADERSTYLE" in the Command Line.  
2\) The Multileader Style Manager dialog box appears.  
![][image2]  
3\) Configure the necessary options in the dialog box.  
4\) The new style settings are applied to the created leaders.
