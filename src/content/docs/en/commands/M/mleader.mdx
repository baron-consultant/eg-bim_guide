* Creates a leader line together with text, letting you quickly insert annotations that describe an object or location in the drawing.

![][image1]

# **1\. Creating a Leader** [**Demo Video**](https://youtu.be/m--OHWxgEJY)

1\) Type "MLEADER" in the Command Line.  
2\) Click to specify the leader's start point.  
3\) Click to specify where the text or block will be placed.  
4\) Enter text or specify a block, and a multileader is created together with the leader line.
