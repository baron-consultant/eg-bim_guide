- Creates or manages viewports in the Layout Space.

![][image1]

## **1\. Creating a Viewport** [**Demo Video**](https://youtu.be/ggBU-d58_AE)

1\) Go to the Layout tab.  
2\) Type "MVIEW" in the Command Line.  
3\) Select one of the options displayed in the Command Line.

| Option    | Description                                                |
| :-------- | :---------------------------------------------------------- |
| ON/OFF    | Activates (ON) or deactivates (OFF) the selected viewport.  |
| Fit       | Automatically zooms the viewport to fit the current drawing area. |
| Lock      | Locks (ON) or unlocks (OFF) the viewport scale.            |
| Entity    | Converts an existing object (e.g., a rectangle or circle) into a viewport. |
| Polygonal | Creates a new viewport in a polygonal shape.               |
