* A function that automatically merges multiple multileader objects into a single annotation.

![][image1]

## **1\. Merging Leaders** [**Demo Video**]()

1\) Type "MLEADERCOLLECT" in the Command Line.  
2\) Select all multileader (MLEADER) objects that have the same text.  
3\) The selected leaders are merged into a single annotation text, and the multiple arrows are automatically arranged to point to that text.  
Note: Leaders with different text are not merged.
