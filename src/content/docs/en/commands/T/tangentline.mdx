- Automatically creates a straight line tangent to circular objects.

![][image1]

## **1\. Creating a Tangent Line** [**Demo Video**](https://youtu.be/pOj5WyXpKuY)

1\) Type "TANGENTLINE" in the Command Line.  
2\) In the dialog box, set the required items.  
![][image2]  
3\) Select the object (circle or arc) to draw the tangent line on.  
4\) Specify the point through which the tangent line passes.  
5\) Select the tangent line direction.  
6\) Based on the selected conditions, the tangent line is automatically created in the drawing.
