- Lets you select a cell in a table inserted into the drawing and edit it directly.

![][image1]

## **1\. Editing a Table** [**Demo Video**](https://youtu.be/DCJp1teVuLQ)

1\) Run the "TABLEDIT" command in the Command Line.  
2\) Click the cell of the table you want to edit.  
3\) A toolbar appears for the selected cell, allowing you to edit its contents.  
![][image2]

- Change font
- Adjust text height and spacing
- Text style
- Change text color
- Bullets and numbering
- Alignment
- Insert special characters
- Import Text (import external text)
- AutoCAPS (automatic uppercase conversion)

4\) Press ENTER or click outside the cell to apply the changes.  
![][image3]
