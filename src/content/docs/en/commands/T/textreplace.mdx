- Finds a specific string contained in multiple text objects at once and batch-replaces it with different text.

![][image1]

## **1\. Batch Replacing Text** [**Demo Video**](https://youtu.be/QRvho7MqfXE)

1\) Run the "TEXTREPLACE" command.  
2\) Select the multiple text objects to modify.  
3\) Enter specified text content: enter the text content to be changed.  
4\) Enter text content for replacement: enter the text content to replace it with.  
5\) Press ENTER or the SPACE BAR.  
6\) The string is batch-replaced in all selected text.  
![][image2]
