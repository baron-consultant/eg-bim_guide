- A command that automatically creates a text and point pair in the drawing.

![][image1]

## **1\. Creating Text and a Point** [**Demo Video**](https://youtu.be/vJkM4L-Xim4)

1\) Type "TEXTANDPOINT" in the Command Line.  
2\) In the dialog box, set the required items.  
![][image2]  
3\) Click the coordinate location on screen.  
4\) A point and text showing the corresponding coordinate or elevation (EL) value are simultaneously created at the clicked point.
