- Rotates the selected text object by the desired angle around a base point specified by the user.

![][image1]

## **1\. Rotating Text** [**Demo Video**](https://youtu.be/kXvycWOuXho)

1\) Run the "TEXTROTATE" command in the Command Input Window.  
2\) Select the text object to rotate.  
3\) Specify the first base point (rotation start point).  
4\) Specify the second base point (rotation direction).  
5\) Press ENTER to rotate the selected text based on the two specified points.  
![][image2]
