- Swaps the text content between two selected text objects.

![][image1]

## **1\. Swapping Text Content** [**Demo Video**](https://youtu.be/eNlZng0NCTo)

1\) Run the "TEXTSWAP" command.  
2\) Select the first text object to swap content with.  
3\) Select the second text object to swap content with.  
4\) Press ENTER or the SPACE BAR to swap the text content between the two objects.  
![][image2]
