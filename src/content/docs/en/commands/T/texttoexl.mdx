- Extracts text objects from the drawing and exports them to an Excel file.

![][image1]

## **1\. Exporting Text to Excel** [**Demo Video**](https://youtu.be/7JNcoqOGGXw)

1\) Run the "TEXTTOEXL" command.  
2\) In the TEXTTOEXL dialog box, set the desired options.  
![][image2]  
3\) Select the text objects to export to Excel.  
4\) Press ENTER or the SPACE BAR to complete the selection.  
5\) Excel launches automatically; select the starting cell.  
6\) Click OK to save the selected text content to the Excel sheet.  
![][image3]
