- Specifies two points on the selected object to automatically place a line and text above and below it.

![][image1]

## **1\. Placing Text** [**Demo Video**](https://youtu.be/xyQm8yPXpcc)

1\) Run the "TEXTBTPOINT" command.  
2\) In the TEXTBTPOINT dialog box, set the required options.  
![][image2]  
3\) Select the object to enter text on.  
4\) Select the two reference points (the start point and end point of the line segment) in order.  
5\) The text set in the dialog box for above/below the line is automatically placed.  
![][image3]
