- Copies the content of the selected text object and pastes it into another location or object.

![][image1]

## **1\. Copying Text** [**Demo Video**](https://youtu.be/x5tIIpv0Rs0)

1\) Run the "TEXTCOPY" command.  
2\) Select the source text object to copy.  
3\) Select the target text object to paste the content into.  
4\) Press ENTER or the SPACE BAR.  
5\) The content of the selected text object is copied.  
![][image2]
