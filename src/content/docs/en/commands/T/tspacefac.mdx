[image1]: ../../../../../assets/images/en/commands/tspacefac/image1.png

- Adjusts the line spacing ratio of a text object (MTEXT).

![][image1]

## **1\. Adjusting Line Spacing** [**Demo Video**](https://youtu.be/PZXePIz4aKk)

1\) Run the "TSPACEFAC" command.  
2\) Enter the line spacing ratio. (Valid range: 0.25 \~ 4.0)

- Default: 1.0 (default line spacing)
- \> 1.0: Increases line spacing
- \< 1.0: Decreases line spacing

3\) The line spacing of the MTEXT changes according to the entered value.
