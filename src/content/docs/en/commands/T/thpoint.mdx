- Automatically inserts thousands separators (,) into the selected numeric text to change its display format.

![][image1]

## **1\. Displaying Thousands Separators** [**Demo Video**](https://youtu.be/CgumgA3cpUM)

1\) Run the "THPOINT" command.  
2\) Select the numeric text object to apply the thousands separator to.  
3\) Once the command runs, thousands-separator commas (,) are automatically added to the selected numbers.

- Example: 1000 -> 1,000
