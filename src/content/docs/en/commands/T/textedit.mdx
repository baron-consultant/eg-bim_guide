- Edits single-line text (DTEXT) or multiline text (MTEXT) objects.

![][image1]

## **1\. Entering Special Characters** [**Demo Video**](https://youtu.be/cMg0BHYcWCc)

1\) Run the "TEXTEDIT" command.  
2\) Select the text object to edit.  
3\) When finished editing, press ENTER to end the edit.
