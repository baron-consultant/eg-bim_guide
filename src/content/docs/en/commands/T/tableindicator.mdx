- Sets whether to display row and column numbers for a table inserted into the drawing.

![][image1]

## **1\. Setting Row/Column Number Display** [**Demo Video**](https://youtu.be/pbuYHs_VHCM)

1\) Run the "TABLEINDICATOR" command in the Command Line.  
2\) A message appears asking whether to display row/column numbers.

- 1: Displays column numbers (A, B, C...) at the top and row numbers (1, 2, 3...) on the left of the table
- 0: Hides the numbers, showing the table in its normal form

3\) Press ENTER to apply the setting.
