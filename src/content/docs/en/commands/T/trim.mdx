- Trims the intersecting portion based on the selected object, removing unnecessary parts.

![][image1]

## **1\. Trimming Objects** [**Demo Video**](https://youtu.be/wgC2ma-wI1I)

1\) Run the "TRIM" or "TR" command.  
2\) Select the object to use as the cutting edge (boundary for trimming).  
3\) Press ENTER or the SPACE BAR.  
4\) Click the portion to trim (the unnecessary part of the intersecting line).  
5\) Press ENTER or the SPACE BAR to end the command.
