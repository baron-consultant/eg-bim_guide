* A command that automatically creates a road taper (transition section).

![][image1]

## **1\. Creating a Road Taper** [**Demo Video**](https://youtu.be/114iaSMm4nU)

1\) Type "TAPER" in the Command Input Window.  
2\) In the settings window, select the required options.  
![][image2]  
3\) Select the reference lane (Line or Polyline).  
4\) Following the Command Input Window prompts, enter the following items in order.

- Alignment direction (Y/N)  
- Specify the taper start point

5\) Press the ENTER key to create the taper line.
