- Controls whether the table editing toolbar, which appears when editing a table inserted in the drawing, is displayed.

![][image1]

## **1\. How to Use** [**Demo Video**]()

1\) Run the “TABLETOOLBAR`”` command in the Command Input Window.  
2\) Set whether it is displayed.

- ON: The Table Toolbar is displayed on screen when a table is selected or edited.
- OFF: The Toolbar is not displayed even when a table is selected.

3\) Once the setting is saved, it applies the next time you edit a table.
