- Automatically places text inside the selected polygon (closed polyline, shape).

![][image1]

## **1\. Placing Text** [**Demo Video**](https://youtu.be/yfXmHdjPy5M)

1\) Run the "TEXTINPOL" command.  
2\) In the TEXTINPOL dialog box, select the desired options.  
![][image2]  
3\) Select the point in the drawing where the text will be placed.  
4\) When placement is finished, press the ESC key to end the command.  
![][image3]
