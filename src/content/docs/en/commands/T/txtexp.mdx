- Converts a text object into individual polylines or line segments.

![][image1]

## **1\. Exploding a Text Object** [**Demo Video: Extracting Text Outlines**](https://youtu.be/6so3K_mhmbc)

1\) Run the "TXTEXP" command in the Command Input Window.  
2\) Select the text object to convert into a shape.  
3\) Press ENTER or the SPACE BAR.  
4\) The text is exploded into lines, arcs, or polylines.
