title: TEXTMATCHCOPY

[image1]: ../../../../../assets/images/en/commands/textmatchcopy/image1.png

* A command that copies the properties (font, height, color, alignment, etc.) of the selected source text and applies them identically to other text.

![][image1]

## **1\. Copying Text Properties** [**Demo Video**](https://youtu.be/ZkRdxkkid1I)

1\) Type "TEXTMATCHCOPY" in the Command Input Window.  
2\) Select the source text (Text or Mtext) to use as the reference.  
3\) Select the target text (one or more) to apply the same properties to.  
4\) Press the ENTER key.  
5\) The same properties (font, height, color, alignment, etc.) as the source text are copied and applied to the target text.
