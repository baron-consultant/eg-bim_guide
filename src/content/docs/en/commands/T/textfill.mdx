- Sets whether text objects are displayed as filled characters or as outlines only when plotted.

![][image1]

## **1\. Setting Text Fill Display** [**Demo Video**](https://youtu.be/wcyPGhHWEpQ)

1\) Run the "TEXTFILL" command.  
2\) Enter the option value.

- ON: Displays the interior of the text as filled (default)
- OFF: Displays only the text outline

3\) Press ENTER or the SPACE BAR to apply the setting.  
Note: You must run the "REGEN" command to refresh the screen for the change to take effect.  
![][image2]
