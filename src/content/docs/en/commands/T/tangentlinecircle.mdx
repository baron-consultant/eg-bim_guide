- Automatically creates a common tangent line for a circle or between two circles.

![][image1]

## **1\. Creating a Tangent Line Between Two Circles** [**Demo Video**](https://youtu.be/ofGuG9IuGP8)

1\) Type "TANGENTLINECIRCLE" in the Command Line.  
2\) In the dialog box, set the required items.  
![][image2]  
3\) Following the Command Line prompts, select the first circle, then the second circle.  
4\) Based on the selected type, the tangent line is automatically calculated and created in the drawing.
