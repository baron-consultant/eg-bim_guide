- Specifies two points to set a new User Coordinate System (UCS).

![][image1]

## **1\. Setting the UCS Using Two Points** [**Demo Video**](https://youtu.be/HXvgWUUesYI)

1\) Type "TWOPOINTUCS" in the Command Input Window.  
2\) Following the Command Input Window prompts, specify the two points in order.

- First point: specifies the new origin
- Second point: specifies the X-axis direction

3\) Press the ENTER key.  
4\) The UCS immediately switches to the new reference.  
Note: The Y-axis is automatically calculated perpendicular to the X-axis.
