- Adjusts the display range of the drawing to zoom the screen in or out.

![][image1]

## **1\. Zooming the Screen In and Out** [**Demo Video**](https://youtu.be/77yaTu8UaM4)

1\) Type "ZOOM" in the Command Input Window.  
2\) Press the ENTER key to display the following options.  
3\) Select the desired option to adjust the screen scale.

|        Option        | Description                                                                                            |
| :-----------------: | ----------------------------------------------------------------------------------------------- |
|      In      | Zooms in 2x, centered on the current view.                                                |
|     Out      | Zooms out to 0.5x, centered on the current view.                                              |
|     All      | Displays the entire drawing limits on screen; if no Limits are set, this behaves the same as Extents.                |
|    Center    | Recenters the screen on a specified point and adjusts the zoom by entering the display width.            |
|   Dynamic    | Uses a rectangular frame to visually preview and adjust the area to zoom into.                     |
|   Extents    | Zooms in or out so that all objects in the drawing fill the screen.                           |
|  Left   | Pans the screen to the left.                                                                     |
|   Previous   | Reverts to the previous zoom state.                                                               |
| Right | Pans the screen to the right.                                                                   |
|     Window     | Specify two points with the mouse to zoom in on that area only.                                          |
|    Entity    | Zooms in based on the selected object so that it fills the screen.                     |
|    Scale     | Directly enter the zoom scale. (e.g., 2X \= 2x zoom in, 0.5X \= half zoom out, 1XP \= 1:1 print scale) |
