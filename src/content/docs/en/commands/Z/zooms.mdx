- Adjusts the screen's display scale to the value entered by the user.

![][image1]

## **1\. Zooming the Screen by Scale** [**Demo Video**](https://youtu.be/O4EB_Fn_yzM)

1\) Type "ZOOMS" in the Command Input Window.  
2\) Press the ENTER key.  
3\) Enter the desired zoom scale value or format.  
4\) The screen zooms in or out according to the entered scale value.  
![][image2]
