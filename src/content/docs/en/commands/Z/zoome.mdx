---
title: ZOOME
---

[image1]: ../../../../../assets/images/en/commands/zoome/image1.png

- Zooms in or out so that all objects in the drawing fit exactly within the screen boundaries.

![][image1]

## **1\. Displaying the Entire Drawing** [**Demo Video**](https://youtu.be/6_OWlO6q7ro)

1\) Type "ZOOME" in the Command Input Window.  
2\) Press the ENTER key.  
3\) The screen adjusts automatically, and all objects in the drawing are displayed in full.
