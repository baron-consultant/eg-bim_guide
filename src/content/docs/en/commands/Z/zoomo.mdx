title: ZOOMO
---

[image1]: ../../../../../assets/images/en/commands/zoomo/image1.png

- Zooms in based on a selected object so that it is displayed as large as possible on screen.

![][image1]

## **1\. Zooming In Based on an Object** [**View Demo Video**](https://youtu.be/M_TI7Bj8vcs)

1\) Type "ZOOMO" in the Command Line.  
2\) Press the ENTER key.  
3\) Select the object you want to zoom in on.  
4\) Press the ENTER key, and the selected object is zoomed in to fill the screen.
