title: ZOOMP
---

[image1]: ../../../../../assets/images/en/commands/zoomp/image1.png

- A shortcut command for the ZOOM command's Previous option, returning to the immediately preceding screen scale.

![][image1]

## **1\. Returning to the Previous View** [**Demo Video**](https://youtu.be/wSnSxsq8mgY)

1\) Type "ZOOMP" in the Command Input Window.  
2\) Press the ENTER key.  
3\) The previous zoom state is restored. (Returns to the screen position and scale from the last time ZOOM was run.)
