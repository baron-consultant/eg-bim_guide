- An advanced "Quick Select" tool that lets you specify object type and selection rule (window/crossing/boundary) together in the drawing to quickly select only the objects that match those conditions.

![][image1]

## **1\. Selecting Specific Objects** [**Demo Video**](https://youtu.be/rAlOoyDTbrQ)

1\) Type "QSELECT2" in the Command Line.  
2\) Configure the required settings in the dialog box that appears.  
![][image2]  
3\) When you select objects, only those matching the specified conditions are selected.
