- Quickly selects objects in the drawing based on specific conditions (e.g., layer, color, object type).

![][image1]

## **1\. Selecting Specific Objects** [**Demo Video**](https://youtu.be/omwjnexGy-8)

1\) Type "QSELECT" in the Command Line.  
2\) The Quick Select dialog box appears.  
![][image2]  
3\) Select the required items in the dialog box.  
4\) Once the settings are complete, objects matching the conditions are quickly selected.
