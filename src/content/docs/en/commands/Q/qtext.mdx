- Simplifies and displays all text in the drawing using quick text display.

![][image1]

## **1\. Setting Text Display State** [**Demo Video**](https://youtu.be/JhnMX0BsOQk)

1\) Run the "QTEXT" command.  
2\) Enter whether to enable the display setting:

- ON: Displays text as a rectangle (or simple frame) instead of the actual text
- OFF: Displays text normally (default)

3\) Press the ENTER key or the Space bar to apply the setting.  
Note: Use the "REGEN" command to refresh the screen for the change to take effect.
