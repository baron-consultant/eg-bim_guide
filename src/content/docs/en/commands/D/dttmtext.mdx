- Converts DTEXT (single-line text) to MTEXT (multiline text).

![][image1]

## **1\. Converting to Multiline Text** [**Demo Video**](https://youtu.be/zqcnF74bkYE)

1\) Run the "DTTMTEXT" command in the Command Input Window.  
2\) Set the desired options in the DTTMTEXT dialog box.  
![][image2]  
3\) Select the single-line text object (DTEXT) to convert.  
4\) Press ENTER or the SPACE BAR.  
5\) The selected text is converted into a single MTEXT object.
