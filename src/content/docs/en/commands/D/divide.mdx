- Divides an object into a specified number of equal segments and automatically places points or blocks.

![][image1]

## **1\. Dividing an Object Equally** [**Demo Video**](https://youtu.be/LdM5x0GVGF8)

1\) Run the "DIVIDE" command.  
2\) Select the object (line, polyline, circle, arc, etc.) to divide equally.  
3\) Press ENTER or the SPACE BAR to complete the selection.  
4\) Enter the number of segments to divide into.  
5\) Press ENTER or the SPACE BAR.  
6\) The object is divided equally into the specified number of segments, and points or blocks are automatically placed.  
![][image2]
