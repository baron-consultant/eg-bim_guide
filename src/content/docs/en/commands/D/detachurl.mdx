- Deletes the hyperlink attached to an object so that the link no longer opens from that object.

![][image1]

## **1\. Removing an Object Hyperlink** [**Demo Video**](https://youtu.be/ByrKw7sNURg)

1\) Run the "DETACHURL" command.  
2\) Select an object with a hyperlink attached (line, polyline, block, image, etc.).  
3\) Press ENTER to complete the selection.  
4\) All hyperlinks attached to the selected object are removed.  
![][image2]
