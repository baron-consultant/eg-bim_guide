* A system variable that controls how dimension objects are associated with elements in the drawing.

![][image1]

## **1\. Configuring Dimension Association** [**Demo Video**](https://youtu.be/ZVlsS0Kj5qY)

1\) Type "DIMASSOC" in the Command Line.  
2\) Select and enter one of the options below.

| Value | Description |
| :---: | ----- |
| 0 | Dimension elements (lines, arrows, text, etc.) are created as separate, unassociated objects. |
| 1 | The dimension is created as non-associative. The dimension object is a single object, but it is not linked to the original elements (lines, points, etc.). |
| 2 | The dimension is created as associative. The dimension is linked to the referenced object, and its value updates automatically when the object is moved or modified. (Default, recommended.) |

3\) Press the ENTER key to apply the option.
