* A command that controls whether the frame (border line) of a DWF underlay object inserted in the drawing is displayed.

![][image1]

## **1\. Setting DWF Frame Display** [**Demo Video**]()

1\) Type "DWFFRAME" in the Command Input Window.  
2\) Enter the value that specifies the frame display state.

| Value | Description |
| :---: | ----- |
| 0 | The frame is not displayed, and does not appear when printed. |
| 1 | The frame is displayed, and is also printed. |
| 2 | The frame is displayed, but is not printed. |

3\) Press the ENTER key to apply the setting.  
Note:  If the change is not immediately reflected on screen, refresh the display using the "REGEN" command.
