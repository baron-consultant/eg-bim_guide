![][image1]

## **1\. Creating Single-Line Text** [**Demo Video**](https://youtu.be/FL-7sKf508M)

1\) Run the "DTEXT" or "DT" command.  
2\) Specify the start point for placing the text on the screen.  
3\) Enter the text height (character size).  
4\) Enter the rotation angle of the text.  
5\) Type the text string using the keyboard.  
6\) Press the ESC key to complete the text entry and place it on the screen.
