* A command that controls whether the frame (border line) of a DGN underlay object inserted in the drawing is displayed.

![][image1]

## **1\. Setting DGN Frame Display** [**Demo Video**](https://youtu.be/OHmdAFS9RCQ)

1\) Type "DGNFRAME" in the Command Line.  
2\) Enter a value to specify the frame display state.

| Value | Description |
| :---: | ----- |
| 0 | The frame is not displayed and does not appear when printed. |
| 1 | The frame is displayed and is also printed. |
| 2 | The frame is displayed but does not appear when printed. |

3\) Press the ENTER key to apply the setting.  
Note: If the change is not immediately reflected on screen, run the "REGEN" command to refresh the display.
