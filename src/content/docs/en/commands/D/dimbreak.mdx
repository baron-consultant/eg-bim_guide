title: DIMBREAK

[image1]: ../../../../../assets/images/en/commands/dimbreak/image1.png

* A command that automatically creates a gap when a dimension line or extension line overlaps another line or object.

![][image1]

## **1\. Breaking a Dimension Line** [**Demo Video**](https://youtu.be/FI8Mf6z8RXg)

1\) Type "DIMBREAK" in the Command Input Window.  
2\) Following the Command Input Window prompts, enter values in the order below.

- Enter base scale value: the drawing's current scale value  
- Enter scale value to change: the scale value to apply

3\) Select the dimension object(s) to change.  
4\) Press the ENTER key to adjust the scale of all selected dimension objects to match the entered ratio.
