- Measures the radius of the selected circle or arc and displays it as a jogged dimension.

## **1\. Entering a Jogged Radius Dimension** [**Demo Video**](https://youtu.be/dXi_kX6E3Hw)

1\) Run the "DIMJOGGED" command.  
![][image1]  
2\) Select the circle or arc in the drawing whose radius you want to measure.  
3\) Specify the new center point for the jogged radius dimension.  
![][image2]  
4\) Move the mouse and click at the desired position for the dimension text.  
5\) Move the mouse and click at the desired angle for the dimension line.  
![][image3]

## **2\. Changing the Angle of the Jogged Radius Dimension Text** [**Demo Video**](https://youtu.be/n7_rcm9D44M)

1\) Run the "DIMJOGGED" command, then select the circle or arc in the drawing whose radius you want to measure.  
2\) Click the Angle option and enter an angle value; the dimension text is placed at the specified angle. (The default value is 0 degrees.)  
![][image4]  
![][image5]  
![][image6]

## **3\. Entering the Jogged Radius Dimension Text as Multiline Text** [**Demo Video**](https://youtu.be/UKoT_Ix62LI)

1\) Run the "DIMJOGGED" command, then select the circle or arc in the drawing whose radius you want to measure.  
2\) Click the Mtext option; the Text Editor toolbar appears and the dimension text enters edit mode, allowing you to enter multiple lines of text.  
![][image7]  
![][image8]  
3\) Click the Done button (V) on the Text Editor toolbar, or click an empty area of the drawing, to end editing.  
![][image9]

## **4\. Changing the Diameter Dimension Text** [**Demo Video**](https://youtu.be/gpNuzQw1Mc0)

1\) Run the "DIMJOGGED" command, then select the circle or arc in the drawing whose radius you want to measure.  
2\) Click the Text option and enter the replacement text.  
![][image10]  
3\) Press ENTER, then place the diameter dimension at the desired location in the drawing.  
![][image11]
