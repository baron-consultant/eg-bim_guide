* Combines several separate dimensions into a single continuous dimension.

![][image1]

## **1\. Combining Dimensions** [**Demo Video**](https://youtu.be/Ax2W64MrRms)

1\) Type "DIMJOIN" in the Command Input Window.  
2\) Select the first dimension object to use as the reference.  
3\) Select the remaining dimension objects to combine, in order.  
4\) Press the ENTER key.  
5\) The selected dimensions are automatically aligned and combined into a single continuous dimension line.
