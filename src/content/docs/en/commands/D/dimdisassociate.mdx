[image1]: ../../../../../assets/images/en/commands/dimdisassociate/image1.png

* Disassociates a dimension from its associated object.

![][image1]

## **1.Disassociating a Dimension** [**Demo Video**](https://youtu.be/HfKQLksZDaw)

1\) Type "DIMDISASSOCIATE" in the Command Line.  
2\) Select the dimension object to disassociate.  
3\) Press the ENTER key.  
4\) The selected dimension will no longer update automatically when the original object is moved or modified.
