title: DIMXLINE

[image1]: ../../../../../assets/images/en/commands/dimxline/image1.png

* Creates an extension line independently, or generates only the extension line for an existing dimension.

![][image1]

## **1\. Creating an Extension Line** [**Demo Video**](https://youtu.be/mmAhuPW7RCE)

1\) Type "DIMXLINE" in the Command Line.  
2\) Select the dimension.  
3\) Following the Command Line prompts, select the points.

- First point: the start point of the extension line  
- Second point: the end point of the extension line

4\) The extension line is created based on the selected dimension.
