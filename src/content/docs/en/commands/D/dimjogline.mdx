- Adds or removes a jog line on a linear dimension (DIMLINEAR) or an aligned dimension (DIMALIGNED).

## **1\. Adding a Jog Line to a Linear Dimension** [**Demo Video**](https://youtu.be/nnYI1bDZRX4)

1\) Run the "DIMJOGLINE" command and select Add.  
![][image1]  
2\) Select the dimension to add the jog line to, then press ENTER.  
![][image2]  
3\) Click at the location where you want to add the jog line.  
![][image3]

## **2\. Removing a Jog Line from a Linear Dimension** [**Demo Video**](https://youtu.be/Xp8Ja1C1UxM)

1\) Run the "DIMJOGLINE" command and select Remove.  
![][image4]  
2\) Select the linear dimension whose jog line you want to remove.  
![][image5]  
![][image6]
