[image1]: ../../../../../assets/images/en/commands/dimlineposition/image1.png

* Aligns the selected dimension lines to a common baseline.

![][image1]

## **1\. Aligning Dimension Lines** [**Demo Video**](https://youtu.be/6ygghQX2rEE)

1\) Type “DIMLINEPOSITION” in the Command Input Window.  
2\) Select multiple dimension lines to align.  
3\) Press the ENTER key.  
4\) Click the alignment reference point.  
5\) All selected dimension lines are aligned to that reference position.
