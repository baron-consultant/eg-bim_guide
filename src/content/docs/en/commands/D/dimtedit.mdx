* Modifies the position or orientation of dimension text.

![][image1]

## **1\. Modifying the Text Position** [**Demo Video**](https://youtu.be/-Qrk0du9UOU)

1\) Type "DIMTEDIT" in the Command Line.  
2\) Click the dimension line you want to modify.  
3\) The following options appear in the Command Line.  
4\) Select the desired option, or specify the position directly with the mouse.

| Option | Description |
| :---: | :---: |
| Left | Aligns the text to the left of the dimension line |
| Right | Aligns the text to the right of the dimension line |
| Center | Aligns the text to the center of the dimension line |
| Home | Restores the text to its default (home) position on the dimension line |
| Angle | Rotates the text to a specified angle |

5\) The dimension position is updated.
