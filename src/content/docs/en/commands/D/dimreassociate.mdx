* Reassociates the relationship between an object and a dimension.

![][image1]

## **1\. Restoring a Dimension Association** [**Demo Video**](https://youtu.be/EJ2-6wvEiJc)

1\) Type "DIMREASSOCIATE" in the Command Line.  
2\) Select the dimension that is in a non-associative state.  
3\) Specify the first point, then the second point.  
4\) Press the ENTER key; the dimension is reassociated with the selected object and restored to an automatically updating associative dimension.
