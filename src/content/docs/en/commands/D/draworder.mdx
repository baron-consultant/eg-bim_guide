- Changes the display order of objects in the drawing.

![][image1]

## **1\. Changing the Object Display Order** [**Demo Video**](https://youtu.be/90-goAqJffk)

1\) Run the "DRAWORDER" command.  
2\) Select the object (line, hatch, image, block, etc.) whose display order you want to change.  
3\) Press ENTER or the SPACE BAR to complete the selection.  
4\) Select one of the following options:

- Front → Brings the selected object to the front
- Back → Sends the selected object to the back
- Above objects → Moves the object above a specific object
- Under objects → Moves the object below a specific object
