* Evenly divides the selected dimension into the specified number of equal segments.

![][image1]

## **1\. Evenly Dividing a Dimension** [**Demo Video**](https://youtu.be/wYtpzOdrfMM)

1\) Type "DIDEQUALPART" in the Command Line.  
2\) Select the existing dimension object to divide.  
3\) Enter the desired number of divisions (e.g., 4\).  
4\) The overall dimension is evenly divided into the entered number of segments, and a partial dimension line is displayed for each segment.
