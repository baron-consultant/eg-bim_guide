## **1\. Deleting a Polyline Vertex** [**Demo Video**](https://youtu.be/TkE-yjruCw4)

1\) Run the "DELPVE" command.  
2\) Select the polyline object whose vertex you want to delete.  
3\) Click the mouse on the vertex you want to delete. (The command ends automatically when there are no more vertices to delete.)  
4\) To end the command, press the "ESC" key.
