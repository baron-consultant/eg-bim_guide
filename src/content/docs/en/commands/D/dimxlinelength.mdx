* Adjusts the length of the extension line on an existing dimension.

![][image1]

## **1\. Adjusting the Extension Line Length** [**Demo Video**](https://youtu.be/QW7ZFbVq5Hg)

1\) Type "DIMXLINELENGTH" in the Command Line.  
2\) Select the desired option from the settings.  
![][image2]  
2\) Select the dimension object whose extension line length you want to adjust.  
3\) Specify the extension line length.  
4\) The extension line length is adjusted according to the entered value.
