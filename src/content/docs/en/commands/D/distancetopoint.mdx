- Automatically calculates the distance (Length) between two points and displays it as text.

![][image1]

## **1\. Measuring a Distance** [**Demo Video**](https://youtu.be/brD3fbc6EiE)

1\) Type "DISTANCETOPOINT" in the Command Input Window.  
2\) Following the Command Input Window prompts, specify the base point.  
3\) Then click the point to calculate the distance to.  
4\) The straight-line distance between the base point and the selected point is calculated and displayed in the Command Input Window.  
5\) You can also insert the distance value as text at the selected location or at the midpoint.  
Note: If you select multiple points in succession, the distance from the base point to each point is displayed in order.
