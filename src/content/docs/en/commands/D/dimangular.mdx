* Measures an angle and displays the value as a dimension on the drawing.

![][image1]

## **1\. Measuring an Angle** [**Demo Video**](https://youtu.be/iKqawY1fqso)

1\) Type "DIMANGULAR" in the Command Line.  
2\) You can define the angle by selecting one of the following.

- Select two intersecting lines in sequence  
- Click an arc to measure its central angle

3\) Following the Command Line prompts, click to specify the location of the dimension line.  
4\) The angular dimension (°) is displayed based on the selected lines or points.
