[image1]: ../../../../../assets/images/en/commands/donut/image1.png

- Creates a donut using a polyline.
- You can set property values to draw the DONUT.

### DONUT Setting Option Keywords

![][image1]

| Option         | Description                          |
| :------------- | :----------------------------------- |
| 2Point         | Creates a DONUT by specifying 2 points. |
| 3Point         | Creates a DONUT by specifying 3 points. |
| RadTanTan(RTT) | Creates a DONUT tangent to two objects. |

<br />

## **1\. Drawing a Donut** [**Demo Video**](https://youtu.be/saj9LwPB9zE)

1\) Run the "DONUT" command.  
2\) Enter the inside diameter.  
3\) Enter the outside diameter.  
4\) Click on the screen with the mouse.  
5\) Press the ENTER or ESC key to end the drawing.

## **2\. Drawing a Donut \- 2Point** [**Demo Video**](https://youtu.be/Qhzvj2-QApU)

1\) Run the "DONUT" command.  
2\) Enter the 2Point keyword and enter the Width.  
3\) Specify the first point with the mouse.  
4\) Specify the second point with the mouse.

## **3\. Drawing a Donut \- 3Point** [**Demo Video**](https://youtu.be/1oAuFECMMsQ)

1\) Run the "DONUT" command.  
2\) Enter the 3Point keyword and enter the Width.  
3\) Specify the first point with the mouse.  
4\) Specify the second point with the mouse.  
5\) Specify the third point with the mouse.

## **4\. Drawing a Donut \- RadTanTan(RTT)** [**Demo Video**](https://youtu.be/8cxAGDF_ncA)

1\) Run the "DONUT" command.  
2\) Enter the RadTanTan keyword and enter the Width.  
3\) Enter the diameter.  
4\) Select the tangent point on the first object. (The object can be a Line, Circle, Arc, or Polyline.)  
5\) Select the tangent point on the second object. (The object can be a Line, Circle, Arc, or Polyline.)
