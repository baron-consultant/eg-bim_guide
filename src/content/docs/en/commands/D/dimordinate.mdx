title: DIMORDINATE
---

[image1]: ../../../../../assets/images/en/commands/dimordinate/image1.png

* Displays the X or Y coordinate value of a specified point as a dimension.

![][image1]
 
## **1\. Displaying a Coordinate** [**Demo Video**](https://youtu.be/VK-XwwrcU2E)

1\) Type "DIMORDINATE" in the Command Input Window.  
2\) Click the point whose coordinate you want to display.  
3\) Click to specify the location of the dimension line.  
4\) Move the mouse in the direction you want to display; the X or Y coordinate value appears automatically.
