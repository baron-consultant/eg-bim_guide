* Automatically divides and displays a dimension line according to a specified number of divisions.

![][image1]

## **1\. Dividing a Dimension** [**Demo Video**](https://youtu.be/yPqLAw0SttY)

1\) Type "RESETDIMTEXT" in the Command Input Window.  
2\) Select the dimension object to divide.  
3\) Enter the number of divisions. (For example, entering 4 divides it into 4 equal parts.)  
4\) Press the ENTER key.  
5\) The selected dimension segment is automatically divided and displayed evenly according to the entered number.
