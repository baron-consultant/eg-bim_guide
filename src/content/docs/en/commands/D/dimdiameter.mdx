- Measures the diameter of the selected circle or arc and displays it as dimension text.

## **1\. How to Enter a Diameter Dimension** [**Demo Video**](https://youtu.be/YG4XG2NXVzs)

1\) Run the "DIMDIAMETER" command.  
![][image1]  
2\) Select the circle or arc in the drawing to measure the diameter of.  
![][image2]  
3\) Insert the dimension text at the desired location.  
![][image3]  
![][image4]

## **2\. Changing the Angle of the Diameter Dimension Text** [**Demo Video**](https://youtu.be/4h1Fu4pU9lc)

1\) Run the "DIMDIAMETER" command, and select the circle or arc in the drawing to measure the diameter of.  
2\) Click the Angle option and enter an angle value; the dimension text is then entered at the specified angle. (The default is 0 degrees.)  
![][image5]  
![][image6]

## **3\. How to Enter Diameter Dimension Text as Multiline Text** [**Demo Video**](https://youtu.be/ECs3SXsBAeQ)

1\) Run the "DIMDIAMETER" command, and select the circle or arc in the drawing to measure the diameter of.  
2\) Click the Mtext option; the Text Editor toolbar appears and the dimension text enters edit mode, then enter the text on multiple lines.  
![][image7]  
![][image8]  
3\) Click the Done button (V) on the Text Editor toolbar, or click an empty area of the drawing to finish editing.  
![][image9]

## **4\. How to Change the Diameter Dimension Text** [**Demo Video**](https://youtu.be/sS0_D01lDKQ)

1\) Run the "DIMDIAMETER" command, and select the circle or arc in the drawing to measure the diameter of.  
2\) Click the Text option, and enter the text string to change.  
![][image10]  
3\) Press ENTER, then place the diameter dimension at the desired location in the drawing.  
![][image11]
