[image1]: ../../../../../assets/images/en/commands/dimdivide/image1.png

* Divides the selected dimension into the specified number of equal segments.

![][image1]

## **1\. Dividing a Dimension** [**Demo Video**](https://youtu.be/mwilLLt6KIo)

1\) Type "DIMDIVIDE" in the Command Line.  
2\) Select the existing dimension object to divide.  
3\) Select the segment to divide.  
4\) The dimension line is divided at the selected point, creating a partial dimension.
