* Quickly edits a dimension's text position, rotation angle, or content.

![][image1]

## **1\. Editing Dimension Position** [**Demo Video**](https://youtu.be/O7X1yMtUGzI)

1\) Type "DIMEDIT" in the Command Input Window.  
2\) Select and enter one of the options below.

| Value | Description |
| :---: | ----- |
| Home(H) | Returns the dimension text to its original (default) position. |
| New (N) | Replaces the existing dimension value with new text. |
| Rotate (R) | Rotates the dimension text horizontally or vertically. |
| Oblique (O) | Specifies the oblique angle of the extension lines to display them at a slant. |

3\) Press the ENTER key to apply the option.
