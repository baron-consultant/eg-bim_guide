- Automatically calculates the distance (Length) between two points and displays it as text.

![][image1]

## **1\. Displaying a Distance** [**Demo Video**](https://youtu.be/sgAV2UzirlI)

1\) Type "DISTANCETEXT" in the Command Line.  
2\) Type S in the Command Line to open the settings dialog box.  
![][image2]  
3\) Select the desired options in the dialog box.  
3\) Following the Command Line prompts, specify the two points in order.

- First point: the starting point for the distance measurement
- Second point: the ending point for the distance measurement

5\) The straight-line distance between the two points is displayed in the Command Line, and the distance value is simultaneously inserted as text at that location.
