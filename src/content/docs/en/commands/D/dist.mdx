- A command that measures the distance and angle between two points.

![][image1]

## **1\. Measuring a Distance** [**Demo Video**](https://youtu.be/JM1TwSa103Y)

1\) Type "DIST" in the Command Line.  
2\) Following the Command Line prompts, specify the first point.  
3\) Specify the second point.  
4\) The distance and angle are automatically displayed in the Command Line.
