- Measures the radius of the selected circle or arc and displays it as dimension text.

## **1\. Entering a Radius Dimension** [**Demo Video**](https://youtu.be/EWwk_uQWwqc)

1\) Run the "DIMRADIUS" command.  
![][image1]  
2\) Select the circle or arc in the drawing whose diameter you want to measure.  
![][image2]  
3\) Insert the dimension text at the desired location.  
![][image3]

## **2\. Changing the Angle of the Diameter Dimension Text** [**Demo Video**](https://youtu.be/CneaY-oIGNI)

1\) Run the "DIMRADIUS" command, then select the circle or arc in the drawing whose radius you want to measure.  
2\) Click the Angle option and enter an angle value; the dimension text is placed at the specified angle. (The default value is 0 degrees.)  
![][image4]  
![][image5]

## **3\. Entering the Diameter Dimension Text as Multiline Text** [**Demo Video**](https://youtu.be/kT_B38T5UqA)

1\) Run the "DIMRADIUS" command, then select the circle or arc in the drawing whose radius you want to measure.  
2\) Click the Mtext option; the Text Editor toolbar appears and the dimension text enters edit mode, allowing you to enter multiple lines of text.  
![][image6]  
![][image7]  
![][image8]

## **4\. Changing the Diameter Dimension Text** [**Demo Video**](https://youtu.be/svp6vQ0TJLo)

1\) Run the "DIMRADIUS" command, then select the circle or arc in the drawing whose radius you want to measure.  
2\) Click the Text option and enter the replacement text.
