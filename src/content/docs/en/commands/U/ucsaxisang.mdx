[image1]: ../../../../../assets/images/en/commands/ucsaxisang/image1.png

- A system variable that controls the angle (axis rotation angle) between the X-axis direction of the current UCS and the screen's reference X-axis.

![][image1]

## **1\. Rotating the UCS Around Its Axis** [**Demo Video**](https://youtu.be/Gzt35i7FeVo)

1\) Type "UCSAXISANG" in the Command Input Window.  
2\) In the Command Input Window, enter the desired angle (in degrees).

- Example: 45 -> Rotates the UCS 45 degrees relative to the screen
- Example: 90 -> Rotates the UCS to a vertical orientation

3\) Press the ENTER key to complete the setting.
