- Ungroups an existing group, returning the objects to individual elements.

![][image1]

## **1\. Ungrouping Objects** [**Demo Video**](https://youtu.be/avQoSHyWXaw)

1\) Run the "UNGROUP" command in the Command Line.  
2\) Select the group object to ungroup.  
3\) Press ENTER or the SPACE BAR.  
4\) The selected group is ungrouped, and the objects are separated into individual elements.  
![][image2]
