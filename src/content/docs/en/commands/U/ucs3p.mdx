- Defines a new User Coordinate System by specifying three points (origin, X-axis direction point, and Y-axis direction point).

![][image1]

## **1\. Setting the UCS Using Three Points** [**Demo Video**](https://youtu.be/zLTYCZzrMes)

1\) Type "UCS3P" in the Command Input Window.  
2\) Following the Command Input Window prompts, specify the three points in order.

- First point: specifies the new origin
- Second point: specifies the X-axis direction
- Third point: specifies the Y-axis direction

3\) Press the ENTER key.  
4\) The UCS immediately switches to the new reference.
