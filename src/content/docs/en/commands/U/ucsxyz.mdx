[image1]: ../../../../../assets/images/en/commands/ucsxyz/image1.png

- Sequentially rotates the X, Y, and Z axes of the current UCS by 90 degrees each.

![][image1]

## **1\. Rotating the UCS Around an Axis** [**Demo Video**](https://youtu.be/NLhgCJrP51E)

1\) Type "UCSXYZ" in the Command Line.  
2\) The current UCS rotates 90 degrees around the X-axis.  
3\) Entering the command again rotates it 90 degrees around the Y-axis.  
4\) Entering it a third time rotates it 90 degrees around the Z-axis.  
5\) Subsequent entries continue rotating in the cycle X -> Y -> Z.
