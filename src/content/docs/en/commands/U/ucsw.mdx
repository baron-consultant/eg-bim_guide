- Returns the UCS to the World Coordinate System.

![][image1]

## **1\. Returning to the Global Coordinate System** [**Demo Video**](https://youtu.be/_H8dzOKDOJs)

1\) Type "UCSW" in the Command Line.  
2\) Select the required option to set a new coordinate system.  
3\) Press the ENTER key to return the UCS to the default World Coordinate System (WCS).
