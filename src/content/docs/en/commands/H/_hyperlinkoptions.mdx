* A command that sets how hyperlinks are displayed and how they behave.

![][image1]

## **1\. Setting Hyperlink Display Options** [**Demo Video**]()

1\) Type "HYPERLINKOPTIONS" in the Command Line.  
2\) Configure the first option.

- Display hyperlink cursor and shortcut menu?  
(Whether to display the hyperlink icon and right-click menu)  
- Yes: Display the link cursor and shortcut menu  
- No: Do not display

3\) Configure the second option.

- Display hyperlink tooltips? (Whether to display the link address (tooltip) when hovering the mouse)  
- Yes: Display the link address tooltip  
- No: Do not display
