* A command that creates a new boundary line based on an existing hatch object in the drawing.

![][image1]

## **1\. Creating a Hatch Boundary** [**Demo Video**](https://youtu.be/gQYU0bMZ_n4)

1\) Type "HATCHGENERATEBOUNDARY" in the Command Input Window.  
2\) Select the hatch object to create a boundary for.  
3\) Specify the location (layer and shape type) where the boundary will be created.  
4\) The command automatically detects the outline of the hatch and creates a new boundary polyline.
