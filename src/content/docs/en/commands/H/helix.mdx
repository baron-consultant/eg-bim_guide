- Creates a helical spring.
- You can draw a Helix by setting property values of the helical spring, such as center point of base, base radius, top radius, and the height of the helix.

### Helix Diameter/Radius Option Keyword

![][image3]

- Diameter: Enter the diameter instead of the radius.

### Helix Settings Option Keyword

![][image4]

| Option        | Description                                                           |
| :------------ | :------------------------------------------------------------------- |
| Axis endpoint | Directly specify on screen with the mouse where the helix axis ends. |
| Turns         | Sets the number of turns of the helix.                               |
| Turn height   | Sets the height of the helix.                                        |
| Twist         | Sets the rotation direction of the helix. (clockwise/counterclockwise) |

\* If both the Turns and Turn Height options are set, the height of the helical spring is  
automatically determined based on the values of those options.

<br />

## **1\. How to Draw a Helical Spring** [**Demo Video**](https://youtu.be/MoHB-RHOkBc)

1\) Run the "HELIX" command.  
2\) Using the mouse, set the center point of base for the helix on screen.  
3\) Click a point on screen with the mouse to set the base radius, or enter the base radius in the Command Line.  
4\) Click a point on screen with the mouse to set the top radius, or enter the top radius in the Command Line.  
5\) If necessary, set options for the helix.  
&nbsp;&nbsp;&nbsp;&nbsp;5-1) Enter the Axis endpoint keyword to specify where the helical spring's axis ends on screen with the mouse.  
&nbsp;&nbsp;&nbsp;&nbsp;5-2) Enter the Turns keyword and input the number of turns of the helix in the Command Line.  
&nbsp;&nbsp;&nbsp;&nbsp;5-3) Enter the Turn Height keyword and input the height of the helix in the Command Line.  
&nbsp;&nbsp;&nbsp;&nbsp;5-4) Enter the Twist keyword and set the rotation direction of the helix to CW (clockwise) or CCW (counterclockwise).  
6\) Set the height of the helix with the mouse on screen, or enter the height in the Command Line, then  
press ENTER to end the command and draw the helix.
