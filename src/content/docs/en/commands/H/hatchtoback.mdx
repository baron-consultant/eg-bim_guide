* A command that moves a hatch object in the drawing behind all other objects.

![][image1]

## **1\. Sending a Hatch to the Back** [**Demo Video**](https://youtu.be/Fai9yW1PPoY)

1\) Type "HATCHTOBACK" in the Command Input Window.  
2\) The command automatically recognizes all hatch objects in the drawing.  
3\) The display order of the hatches is automatically changed so that they are placed behind all other objects.
