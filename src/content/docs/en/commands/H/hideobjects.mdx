- This function temporarily hides selected objects in the drawing.

![][image1]

## **1\. Hide Objects** [**Demo Video**](https://youtu.be/IsapFetzsyg)

1\) Run the "HIDEOBJECTS" command.  
2\) Select the objects to hide (lines, polylines, blocks, images, hatches, etc.).  
3\) Press ENTER or the SPACE BAR to complete the selection.  
4\) The selected objects are hidden from the screen.  
Note: Run the "UNISOLATEOBJECTS" command to display the hidden objects again.  
![][image2]
