* A command that sets how hyperlinks are displayed and how they behave.

![][image1]

## **1\. Specifying the Hatch Origin** [**Demo Video**](https://youtu.be/Ey8aoGKcQfc)

1\) Type "HATCHSETORIGIN" in the Command Input Window.  
2\) Select the hatch object whose origin you want to change.  
3\) Click the new hatch origin on screen, or enter its coordinates.  
4\) The hatch pattern is realigned based on the selected point.
