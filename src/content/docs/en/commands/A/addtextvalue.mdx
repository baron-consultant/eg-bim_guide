- This function displays the result of a numeric calculation as text at the selected point.

![][image1]

## **1\. Performing Numeric Calculations** [**Demo Video**](https://youtu.be/wNRqXDfsb6U)

1\) Type "ADDTEXTVALUE" in the Command Input Window.  
2\) Select the type of calculation you want.

- P: Addition (Plus)
- M: Subtraction (Minus)
- T: Multiply (Times)
- D: Division (Divide)

3\) Enter the reference value for the calculation.  
4\) Select the text object containing a number in the drawing. (e.g., select a TEXT object reading "25")  
5\) The command automatically performs the calculation, and the result is displayed on the drawing as new text.  
![][image2]
