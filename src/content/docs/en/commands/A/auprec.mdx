[image1]: ../../../../../assets/images/en/commands/auprec/image1.png

- Sets the number of decimal places for angle units in the drawing.

![][image1]

## **1\. Setting Angle Decimal Places** [**Demo Video**](https://youtu.be/LWRDxhDQo6U)

1\) Type "AUPREC" in the Command Input Window.  
2\) Following the prompts displayed in the Command Input Window, enter a number between 0 and 8.  
Example: 4 → Displays up to 4 decimal places  
3\) Press the ENTER key to apply the setting.
