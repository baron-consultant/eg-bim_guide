* This command automatically applies or updates the elevation (EL value) of text or attribute objects in the drawing.

![][image1]

## **1\. Applying a Text Elevation Value to an Object** [**Demo Video**](https://youtu.be/o7g1xPP9JH0)

1\) Type "APPLYELTOTEXT" in the Command Input Window.  
2\) Select the numeric text to apply as the Z value.  
3\) Click the object to reference for the Z value.  
4\) Press the ENTER key.  
5\) The Z value of the selected object is automatically changed to the value of the selected text.
