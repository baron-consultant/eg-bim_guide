- Sets the angle unit format used in the drawing.

![][image1]

## **1\. Setting the Angle Unit** [**Demo Video**](https://youtu.be/Px54H7NVtd8)

1\) Type "AUNITS" in the Command Line.  
2\) Following the Command Line prompts, enter a number between 0 and 4.

| Value  |         Angle Format       |    Example     | Description                                     |
| :----: | :-------------------------: | :-----------: | ------------------------------------------------ |
|   0    |   Decimal Degrees           |    45.0000    | Displayed in the standard degree unit (°)         |
|   1    |   Degrees/Minutes/Seconds   |   45°30'20"   | Displayed in degrees plus minutes/seconds         |
|   2    |       Grads                 |   50.0000g    | 1 revolution \= 400 grad; a surveying unit        |
|   3    |      Radians                |    0.7854r    | Radian unit for math/engineering use              |
|   4    | Surveyor's Units             | N 45°30'20" E | Includes direction (N/S/E/W); used in surveying   |

3\) The angle display unit changes to the format corresponding to the selected number.
