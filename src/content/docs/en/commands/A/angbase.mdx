- This command sets the base direction for angles in the drawing.

![][image1]

## **1\. Setting the Angle Base** [**Demo Video**](https://youtu.be/9zdDb6dWxxY)

1\) Type "ANGBASE" in the Command Line.  
2\) Enter the base angle value in the Command Line.

- 0 \= East (0°) base direction
- 90 \= North (0°) base direction
- 180 \= West (0°) base direction
- 270 \= South (0°) base direction

3\) Press ENTER to apply the setting.
