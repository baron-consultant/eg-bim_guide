* This command arrays and copies objects along a specified path, based on a set spacing or count.

![][image1]

## **1\. Creating a Path Array** [**Demo Video**](https://youtu.be/YUQPeeqajhU)

1\) Type "ARRAYPATH" in the Command Input Window.  
2\) Select the objects to array and press the ENTER key.  
3\) Select the path to array along.  
4\) Set the required options in the Command Input Window or dialog box.

| Option | Description |
| :---: | ----- |
| Associative | Sets whether to keep the array as a single group. - ON: Keeps the arrayed objects as a single associative array (default) - OFF: Creates them as separate individual objects |
| Method | Selects the array method. - Divide: Arrays based on the number of items - Measure: Arrays based on spacing |
| Base point | Specifies the base point to use when duplicating. |
| Tangent direction | Sets whether to align the orientation of the arrayed objects to the tangent direction of the path. |
| Items | Enter the number of objects to array. |
| Rows | Specifies the number of rows when arraying in multiple rows. (Default: 1) |
| Levels | Arrays objects across multiple levels in the Z-axis direction. (For 3D work.) |
| Align items | Sets whether to align objects to the path direction. - ON: Automatically rotates to match the path direction - OFF: Keeps the original angle |
| Z direction | Turns Z-axis alignment on or off. Used to control object orientation on 3D paths. |
| eXit | Completes the array settings and ends the command. |

5\) The array is created along the specified path.
