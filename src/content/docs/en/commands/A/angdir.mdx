---
title: ANGDIR
---

[image1]: ../../../../../assets/images/en/commands/angdir/image1.png

- This command sets the direction in which angles increase in the drawing. In other words, it specifies whether angles increase clockwise or counterclockwise when measuring or entering angles.

![][image1]

## **1\. Setting the Angle Direction** [**Demo Video**](https://youtu.be/PT_xuGTCWFs)

1\) Type "ANGDIR" in the Command Line.  
2\) Following the Command Line prompts, enter either OFF or ON.

- OFF: Angles increase counterclockwise.
- ON: Angles increase clockwise.

3\) Press the ENTER key to apply the setting.
