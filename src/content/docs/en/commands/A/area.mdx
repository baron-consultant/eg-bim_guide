- This command calculates the area and perimeter of a selected region.

![][image1]

## **1\. Calculating Area** [**Demo Video**](https://youtu.be/GyTnsDbHzeI)

1\) Type "AREA" in the Command Line.  
2\) Press the ENTER key.  
3\) Select one of the options in the Command Line.

- Entity: Select a specific object to calculate its area.
- Add: Add multiple areas together.
- Subtract: Subtract a specific area to calculate the net area.

4\) Once the calculation is complete, the area and perimeter are displayed in the Command Line.  
Note: If you click points on an object, an arbitrary polygonal region is specified and its area is calculated.
