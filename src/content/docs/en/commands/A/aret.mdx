- This function calculates the area of an object and automatically displays the value as text.

![][image1]

## **1\. Displaying Area** [**Demo Video**](https://youtu.be/8zElCLrF9C4)

1\) Type "ARET" in the Command Line.  
2\) Following the Command Line prompts, specify the points of the region for which to calculate the area.  
3\) When you finish selecting, press the ENTER key.  
4\) The calculated area is displayed in the Command Line, and the area value is simultaneously inserted into the drawing as text.  
![][image2]
