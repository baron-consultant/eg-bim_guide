- This function automatically aligns text to a specified reference point.

![][image1]

## **1\. Aligning Text** [**Demo Video**](https://youtu.be/8zElCLrF9C4)

1\) Run the "ARTEXT" command.  
2\) Enter "S" and set the desired options in the ARTEXT dialog box.  
![][image2]  
3\) Select the multiple text objects to align.  
4\) Specify the reference point (the point that alignment will be based on).  
5\) All the text is automatically aligned according to the specified reference point.  
![][image3]
