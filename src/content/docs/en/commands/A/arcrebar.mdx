* This function inserts point rebar along an arc.

![][image1]

## **1\. Creating Point Rebar on an Arc** [**Demo Video**](https://youtu.be/zmrX6HCM204)

1\) Type "ARCREBAR" in the Command Input Window.  
2\) Click the arc or polyline curve segment on which to place the point rebar.  
3\) Set the following items in the Command Input Window or dialog box.

- Count (C): Directly specify the number of point rebar.  
- Scale (S): Directly specify the size of the point rebar.  
- Outside (I) / Inside (O): Sets whether to place the point rebar on the outside or the inside.

4\) Once the settings are complete, the point rebar is inserted along the selected arc.
