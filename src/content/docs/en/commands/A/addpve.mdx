- This command adds a vertex to a polyline.
- You can select a regular line object to convert it into a polyline and add a vertex, or select a polyline object to add a vertex at the desired location.

![][image2]- After Adding a Vertex -

## **1\. How to Add a Vertex to a Polyline** [**Demo Video**](https://youtu.be/Ua-NiZE1pII)

1\) Run the "ADDPVE" command.  
2\) Select the polyline to add a vertex to.  
3\) Specify the location on the drawing where the vertex will be added.  
4\) Press the ESC key to end the command.
