* This command enters edit mode so you can edit an array object. With this command, you can modify array components such as the count, spacing, angle, and direction.

![][image1]

## **1\. Editing an Array** [**Demo Video**](https://youtu.be/aPo2uWuuvck)

1\) Type "ARRAYEDIT" in the Command Line.  
2\) Select the array object to edit.  
3\) Select one of the following options.

| Option | Description |
| :---: | ----- |
| Source	 | Edits the source object of the array. Changes to the source are reflected across the entire array. |
| REPlace | Replaces a specific item in the array with another object. |
| Base point | Changes the base point of the array, moving the array's reference position. |
| Rows | Changes the number of rows and their spacing in the array. |
| Columns | Changes the number of columns and their spacing in the array. |
| Levels | Adjusts the number of levels and the height spacing in a 3D array. |
| RESet | Resets the current edits and reverts to the original array settings. |
| eXit | Exits array edit mode. |

4\) Complete the required changes.
