[image1]: ../../../../../assets/images/en/commands/allzvaluechange/image1.png

* This command changes (resets) the Z value of all objects in the drawing at once.

![][image1]

## **1\. Batch-Changing the Z Value of All Objects** [**Demo Video**](https://youtu.be/9b7N1qfEOIg)

1\) Type "ALLZVALUECHANGE" in the Command Input Window.  
2\) Enter the Z value to change to.  
3\) The command scans all objects in the drawing (lines, polylines, text, hatches, etc.) and changes their Z value.
