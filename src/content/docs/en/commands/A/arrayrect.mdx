* This command duplicates a selected object in a grid pattern, spaced evenly in the horizontal, vertical, and height directions.

![][image1]

## **1\. Creating a Rectangular Array** [**Demo Video**](https://youtu.be/EdXQm93DFBo)

1\) Type "ARRAYRECT" in the Command Input Window.  
2\) Select the objects to array and press the ENTER key.  
3\) Set the required options in the Command Input Window or dialog box.

| Option | Description |
| :---: | ----- |
| Associative | Sets whether to keep the array as a single group. - ON: Keeps the arrayed objects as a single associative array (default) - OFF: Creates them as separate individual objects |
| Base point | Specifies the base point of the array. Objects are duplicated in rows and columns around this point. |
| COunt | Specifies the total number of copies. (You can specify the total count directly instead of columns × rows × levels.) |
| Base point | Specifies the base point of the array. Objects are duplicated in rows and columns around this point. |
| Spacing | Specifies the spacing between copies. You can manually enter the horizontal and vertical distance between each object. |
| COLumns | Sets the number of columns (horizontal direction). |
| Rows | Sets the number of rows (vertical direction). |
| Levels | Adds levels in the Z-axis (height) direction. (Used in 3D models.) |
| eXit | Completes the array settings and ends the command. |

4\) The array is created based on the selected object.
