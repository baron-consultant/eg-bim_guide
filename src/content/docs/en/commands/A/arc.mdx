- Creates an arc.
- You can set the arc's property values to draw the ARC.

### Option 1: Setting Option Keywords for ARC

![][image1]

| Option | Description                                                                |
| :----- | :------------------------------------------------------------------------- |
| Center | Specify the center point, then click the start point and end point with the mouse to create the ARC. |
| Follow | The endpoint of the previous object becomes the start point of the arc. Create the ARC by specifying only the endpoint. |

### Option 2: Options After Running ARC and Specifying the Start Point

![][image2]

| Option    | Description                                                                                                 |
| :-------- | :------------------------------------------------------------------------------------------------------------ |
| Angle     | By setting the arc's angle, you can either (1) specify the arc's center point or (2) specify the endpoint.    |
| Center    | By setting the arc's center point, you can either (1) specify the angle or (2) specify the chord length.      |
| Direction | By setting the arc's direction, you can either (1) specify the endpoint based on the start point, or (2) specify the endpoint by setting the angle. |
| End       | By setting the arc's endpoint, you can (1) specify the angle, (2) specify the direction, or (3) specify the radius. |
| Radius    | By setting the arc's radius, you can either (1) specify the included angle and then the direction, or (2) specify the endpoint. |

## **1\. How to Draw an Arc (3-Point Specification: Default Option)** [**Demo Video**](https://youtu.be/yNbpane28ow)

1\) Run the "ARC" command.  
2\) Specify the start point, second point, and endpoint to create the arc.

## **2\. How to Draw an Arc Using the Start Point and Angle** [**Demo Video**](https://youtu.be/AFmTzT-li4U)

1\) Run the "ARC" command.  
2\) Specify the start point \> click the Angle option \> set the angle.  
2-1) Click the Center option and specify the center point to create the arc.  
2-2) Specify the endpoint to create the arc. (default)

## **3\. How to Draw an Arc Using the Start Point and Center Point** [**Demo Video**](https://youtu.be/LNWb7FJ1Otw)

1\) Run the "ARC" command.  
2\) Specify the start point \> click the Center option \> set the center point.  
2-1) Click the Angle option and specify the angle to create the arc.  
2-2) Click the Length of Chord option and specify the chord length to create the arc.  
2-3) Specify the endpoint to create the arc. (default)

## **4\. How to Draw an Arc Using the Start Point, Direction, and Endpoint** [**Demo Video**](https://youtu.be/SKYBst2ia2I)

1\) Run the "ARC" command.  
2\) Specify the start point \> click the Direction option.  
2-1) Click the Follow option and specify the endpoint to create the arc.  
2-2) Specify the arc's initial direction angle and the endpoint to create the arc. (default)

## **5\. How to Draw an Arc Using the Start Point and Endpoint** [**Demo Video**](https://youtu.be/PKIEil8AB4g)

1\) Run the "ARC" command.  
2\) Specify the start point \> click the End option \> set the endpoint.  
2-1) Click the Angle option and specify the angle to create the arc.  
2-2) Click the Direction option and specify the start direction to create the arc.  
2-3) Click the Radius option and specify the radius to create the arc.  
2-4) Specify the center point to create the arc. (default)

## **6\. How to Draw an Arc Using the Start Point and Radius** [**Demo Video**](https://youtu.be/RHK14-e_rCg)

1\) Run the "ARC" command.  
2\) Specify the start point \> click the Radius option \> set the radius.  
2-1) Click the Included Angle option \> specify the angle \> specify the direction to create the arc.  
2-2) Specify the endpoint to create the arc. (default)
