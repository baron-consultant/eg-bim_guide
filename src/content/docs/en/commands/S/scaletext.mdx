- Adjusts the size of the selected text object (DTEXT, MTEXT, dimension text, etc.) to a specified scale factor or height.

![][image1]

## **1\. Adjusting Text Size** [**Demo Video**](https://youtu.be/QLYogais10U)

1\) Run the "SCALETEXT" command in the Command Input Window.  
2\) Select the text object to resize.  
3\) Select Center as the base point for scaling.  
4\) Enter the scale factor to multiply by the current text size.  
5\) Press the ENTER key or the Space bar.  
6\) The size of the selected text is adjusted.  
![][image2]
