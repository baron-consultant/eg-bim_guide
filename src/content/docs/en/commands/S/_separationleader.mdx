* Separates the leader lines connected to a single multileader object into independent, individual leaders.

![][image1]

## **1\. Separating Leader Lines** [**Demo Video**]()

1\) Type "SEPARATIONLEADER" in the Command Line.  
2\) Click the multileader (MLEADER) object to separate.  
3\) Once the command runs, the multiple arrows connected to the multileader are separated into individual leader objects.  
4\) Each leader is converted into a separate annotation with the same text, which can then be edited individually.
