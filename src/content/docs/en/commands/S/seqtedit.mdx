![][image1]

## **1\. Editing Text Consecutively** [**Demo Video**](https://youtu.be/roEGatyxDP0)

1\) Run the "SEQTEDIT" command.  
2\) In the SEQTEDIT dialog box, select the desired options.  
![][image2]  
3\) Select the multiple text objects to edit.  
4\) The selected text objects are activated one at a time, allowing you to edit their content directly.

- After finishing the edit for each text object, press the ENTER key to move to the next text object.

5\) Once all selected text objects have been edited, press the ENTER key to end the command.  
![][image3]
