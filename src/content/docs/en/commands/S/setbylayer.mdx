title: SETBYLAYER

[image1]: ../../../../../assets/images/en/commands/setbylayer/image1.png

- Batch-changes properties such as color, linetype, and lineweight of the selected objects to the ByLayer value. In other words, it forces the objects to follow the properties of the layer they belong to, ignoring their individual object properties.

![][image1]

## **1\. Changing Object Properties to ByLayer** [**Demo Video**](https://youtu.be/sdP6eMB1jQc)

1\) Type "SETBYLAYER" in the Command Input Window.  
2\) Select the objects to change to the ByLayer property.  
3\) Press the ENTER key.  
4\) Select the desired option (YES/NO).

- Color: Changes the color of the object to ByLayer.
- Yes/No option: Choose whether to also change objects inside blocks.

5\) Press ENTER to apply the ByLayer property to the objects according to the selected option.
