[image1]: ../../../../../assets/images/en/commands/sphere/image1.png

- Draws a 3D sphere.

## **1\. Specifying the Radius** [**Demo Video**](https://youtu.be/kWyE5vnCYL4)

1\) Run the SPHERE command.  
2\) Select the coordinate to be the center of the sphere, then specify a circle whose radius is the distance to the mouse point to draw a sphere of that size.

## **2\. Specifying the Diameter** [**Demo Video**](https://youtu.be/TslVx--_KTo)

1\) Run the SPHERE command.  
2\) Select the coordinate to be the center of the sphere, then select the Diameter option in the Command Line.  
![][image1]  
3\) Specify a circle whose diameter is the distance to the mouse point to create a sphere of that size.
