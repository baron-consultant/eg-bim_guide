## **1\. Enlarging / Reducing an Object** [**Reducing an Object Demo Video**](https://youtu.be/bdctIM74BII) [**Enlarging an Object Demo Video**](https://youtu.be/fvnbObdD0jA)

1\) Run the "SCALSE" command.  
2\) Select the object (line, polyline, circle, rectangle, etc.) to resize.  
3\) Specify the base point. (The point that stays fixed while scaling.)  
4\) Enter the scale factor.

- A value greater than 1 enlarges the object (e.g., entering 2 doubles its size).
- A value less than 1 reduces the object (e.g., entering 0.5 halves its size).

5\) Press the ENTER key or the Space bar.  
6\) The selected object is enlarged or reduced according to the specified scale factor.
