title: SPLINEDIT
---

[image1]: ../../../../../assets/images/en/commands/splinedit/image1.png

- A command for editing spline objects.
- This command lets you modify various properties of an already-created spline.

![][image1]

- Option keywords

* Fit data: Adjusts the fit points of the spline.  
(Add / Close / Delete / Move / Purge / Tangents / toLerance)
* Close/Open: Closes or opens the spline.
* Move vertex: Moves the control points of the spline.  
(Next / Previous / Select Point)
* Refine: Adjusts the detailed properties of the spline.  
(Add control point / Elevate order / Weight)
* rEverse: Reverses the direction.
* convert to Polyline: Converts the spline into a polyline.
* Undo: Cancels the last edit.

##

## **1\. Adding a New Point to the Spline - Fit Data_Add**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the Add (A) option keyword.  
4\) Click the start point or end point of the spline with the mouse.  
5\) Click a new point, or enter the After / Before option keyword.  
5-1) Click new points at the desired locations with the mouse, then enter the eXit keyword to end the command.  
5-2) After option: Adds a new point after the selected point. (The new point is inserted  
between the selected point and the next point.)  
5-3) Before option: Adds a new point before the selected point. (The new point is inserted  
between the selected point and the previous point.)  
6\) Enter the eXit (X) keyword or press the Space bar to end the command.

## **2\. Closing/Opening the Spline Object - Fit Data_Close Open**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the Close (C) option keyword.  
3-1) If the object is closed, the Open (O) keyword becomes active.  
3-2) If the object is open, the Close (C) keyword becomes active.  
4\) Enter the eXit (X) keyword or press the Space bar to end the command.

## **3\. Removing a Fit Point from the Spline - Fit Data_Delete**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the Delete (D) option keyword.  
4\) Click the fit point to remove.  
5\) Enter the eXit (X) keyword or press the Space bar to end the command.

## **4\. Moving a Fit Point of the Spline - Fit Data_Move**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the Move (M) option keyword.  
4\) Select the fit point to move, then click the target location with the mouse.  
4-1) Next option: Used to move the next fit point.  
4-2) Previous option: Used to move the previous fit point.  
4-3) Select Point option: Used to directly select a fit point.  
5\) Enter the eXit (X) keyword or press the Space bar to end the command.

## **5\. Replacing Fit Point Data with Control Points - Fit Data_Purge**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the Purge (P) option keyword.  
4\) Press the Space bar or the ENTER key to end the command.

## **6\. Changing the Tangent Direction at the Start and End Points of the Spline** **- Fit Data_Tangents**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the Tangents (T) option keyword.  
4\) Click the start point with the mouse.  
5\) Click the end point with the mouse.  
6\) Press the Space bar or the ENTER key to end the command.

## **7\. Setting the Tolerance of the Spline - Fit Data_toLerance**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Fit data (F) keyword, then enter the toLerance (L) option keyword.  
4\) Enter the tolerance value.  
5\) Press the Space bar or the ENTER key to end the command.

## **8\. Closing the Spline - Close**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Close (C) option keyword.  
3-1) For a closed spline, enter the Open (O) option keyword.  
4\) Press the Space bar or the ENTER key to end the command.

## **9\. Moving a Control Point of the Spline - Move vertex**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Select the control point to move, then click the target location with the mouse.  
3-1) Next option: Used to move the next control point.  
3-2) Previous option: Used to move the previous control point.  
3-3) Select Point option: Used to directly select a control point.  
4\) Enter the eXit (X) keyword or press the Space bar to end the command.

## **10\. Precisely Adjusting the Spline - Refine**

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.  
3\) Enter the Refine (R) option keyword.  
4\) Enter the Add control point / Elevate order / Weight option keyword.  
4-1) Add control point option: Adds a new control point to the spline by clicking with the mouse.  
4-2) Elevate order option: Enter a degree value to create a smoother, more flexible curve.  
4-3) Weight option: Enter the weight of the control point. (Use the N / P / S options to select the control point to change.)  
5\) Enter the eXit (X) keyword or press the Space bar to end the command.

## **11\. Reversing the Direction of the Spline - rEverse**

1\) Before running the command, check the spline object's number in the Properties window.  
2\) Run the "SPLINEDIT" command.  
3\) Select the spline object.  
4\) Enter the rEverse (E) option keyword.  
5\) Press the Space bar or the ENTER key to end the command.  
6\) Check in the Properties window whether the spline object has been reversed.

## **12\. Converting the Spline into a Polyline - convert to Polyline** 

1\) Run the "SPLINEDIT" command.  
2\) Select the spline object.
