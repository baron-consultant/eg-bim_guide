- Creates, modifies, and manages text styles for use in the drawing.

![][image1]

## **1\. Setting a Text Style** [**Demo Video**](https://youtu.be/tUBJdSnCsTs)

1\) Run the "STYLE" command in the Command Input Window.  
2\) In the Text Style dialog box, set the desired options.  
![][image2]  
3\) Click the Apply button to activate it.  
4\) Text created afterward will follow the specified style.  
![][image3]
