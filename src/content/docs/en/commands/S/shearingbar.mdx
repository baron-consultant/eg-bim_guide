* Automatically creates shear reinforcement.

![][image1]

## **1\. Creating Shear Reinforcement** [**Demo Video**](https://youtu.be/pcze6Wko62c)

1\) Type "SHEARINGBAR" in the Command Line.  
2\) Following the Command Line prompts, select the points.

- First point: The starting point of the shear reinforcement.  
- Second point: The ending point of the shear reinforcement.

3\) The shear reinforcement is created along the selected points.
