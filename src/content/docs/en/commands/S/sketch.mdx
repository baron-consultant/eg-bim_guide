title: SKETCH

[image1]: ../../../../../assets/images/en/commands/sketch/image1.png

- Freely draws curves in the drawing.
- Lets you freely sketch curves and create them as line objects.

![][image1]

- Option keywords for SKETCH settings

* ENTER: Creates the sketched object as a line and ends the command.
* Quit: Ends the command and cancels the sketch.
* Pen down: Click with the mouse to stop drawing.
* Pen up: Click with the mouse to resume drawing.
* Erase: Erases lines.
* Write to drawing: Creates the sketched object as a line and continues sketching.
* Connect: Connects the sketched objects.
* Straight to cursor: Draws a straight line to the mouse cursor position.

## **1\. Freely Sketching and Creating a Line Object - ENTER** [**Demo Video**](https://youtu.be/AiE43CLWZ9U)

1\) Run the "SKETCH" command.  
2\) Set the Length of segments value. (Use a smaller value for a precise sketch, or a larger value for a rough sketch.)  
3\) Click with the mouse to sketch freely.  
4\) Enter the ENTER keyword to create the sketched shape as a line object and end the command.

1\) Run the "SKETCH" command.  
2\) Set the Length of segments value. (Use a smaller value for a precise sketch, or a larger value for a rough sketch.)  
3\) Click with the mouse to sketch freely.  
4\) Click with the mouse to stop drawing.  
5\) Position the mouse cursor at the point where the straight line is to be drawn.  
6\) Enter the Straight to cursor (S) keyword.
