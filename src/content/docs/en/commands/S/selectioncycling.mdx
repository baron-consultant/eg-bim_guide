- An option provided when selecting overlapping 2D objects.

| Option | Description |
| :---: | ----- |
| 0 | Display option off  ![][image1] |
| 1 | Displays only the icon at overlapping points  ![][image2] |
| 2 | Displays both the icon and the dialog box at overlapping points  ![][image3] |
| 3 | Displays only the dialog box when selecting at overlapping points  ![][image4] |
