[image1]: ../../../../../assets/images/en/commands/stretch/image1.png

- Stretches or shrinks part of the selected object to reshape it.

![][image1]

## **1\. Stretching / Shrinking an Object** [**Demo Video**](https://youtu.be/bbEvP_V5o5I)

1\) Run the "STRETCH" or "S" command.  
2\) Using a crossing window selection, select the object including the part to be stretched.

- The stretch operation is applied only when the selection includes some, not all, of the object's points.

3\) Press ENTER to complete the selection.  
4\) Specify the base point.  
5\) Specify the second point to set the direction and distance to stretch or shrink.  
6\) The selected part moves by the specified vector, stretching or shrinking the object.
