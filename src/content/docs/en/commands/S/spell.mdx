- Performs a spelling check on text objects in the drawing to identify and correct misspellings.

![][image1]

## **1\. Checking Spelling** [**Demo Video**](https://youtu.be/cw6GpiWhPVs)

1\) Run the "SPELL" command in the Command Input Window.  
2\) Select the text objects to check.  
3\) Press the ENTER key or the Space bar to complete the spelling check for the specified range.  
![][image2]
