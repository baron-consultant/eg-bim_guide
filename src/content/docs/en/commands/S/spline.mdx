- Creates a spline.
- Lets you draw a curve by specifying multiple control points on the screen with the mouse.

### Option Keywords for Drawing/Converting a Spline

![][image1]

| Option | Description                                                                                 |
| :---- | :------------------------------------------------------------------------------------------ |
|       | You can also specify points directly without entering a keyword. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |
| Etity | Converts a spline fitted polyline object into a spline                                             |

### Option Keywords for Drawing a Spline

![][image2]

| Option        | Description                                                            |
| :------------ | :-------------------------------------------------------------------- |
| Close         | Closes the spline. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; |
| Fit tolerance | Sets the tolerance of the curve.                                        |

<br />

## **1\. How to Draw a Spline** [**Demo Video**](https://youtu.be/rhbwh0Btgrw)

1\) Run the "SPLINE" command.  
2\) Specify the spline's first point, second point, and Next Points.  
3\) To change the Fit tolerance of the spline you are currently drawing, enter the Fit tolerance keyword and enter the desired value.  
4\) To finish drawing the spline, press ENTER, then set the tangent for the starting tangent point and the ending point.  
5\) Once the tangent settings are complete, the command ends.

## **2\. How to Draw a Closed Spline** [**Demo Video**](https://youtu.be/Z8ew1O4lvQA)

1\) Run the "SPLINE" command.  
2\) Specify the spline's first point, second point, and Next Point.  
3\) Enter the Close keyword and enter the tangent.  
4\) Once the tangent setting is complete, the command ends.

## **3\. How to Convert a 2D Polyline into a Spline** [**Demo Video**](https://youtu.be/wjU48Xu4j-o)

1\) Run the "SPLINE" command.  
2\) Enter the Entity keyword.  
3\) Select the spline fitted polyline object to convert into a spline.  
4\) Press ENTER to convert the spline fitted polyline into a spline.
