* Automatically places point rebars on a rectangular closed rebar (tie).

![][image1]

## **1\. Creating Rectangular Point Rebars** [**Demo Video**](https://youtu.be/5CcvsQihrIQ)

1\) Type "RECREBAR" in the Command Line.  
2\) Following the Command Line prompts, select the rectangular object.  
3\) In the Command Line or dialog box, set the following items.

- Distance (D): Point rebar spacing  
- Inside_Outside (I): Places the point rebars on the outer or inner side  
- Horizontal_Vertical (H): Places the point rebars in the horizontal or vertical direction  
- Position (P): Point rebar start position

4\) Once the settings are complete, point rebars are automatically inserted along each side of the selected rectangle.
