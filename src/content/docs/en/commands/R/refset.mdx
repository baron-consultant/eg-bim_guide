title: REFSET

[image1]: ../../../../../assets/images/en/commands/refset/image1.png

* A command that adds or removes objects displayed as reference, in addition to the object currently being edited, in external reference or block edit mode.

![][image1]

## **1\. Configuring the Edit Set** [**Demo Video**](https://youtu.be/uOuc5iQwUfk)

1\) Type "REFEDIT" in the Command Input Window to start editing a block or Xref.  
2\) Select the objects to include in the edit set.  
3\) While editing, type "REFSET" in the Command Input Window.  
4\) Select one of the following options.

| Option | Description |
| :---: | ----- |
| Add | Adds a new object to the edit set. |
| Remove | Removes an object from the edit set. |

5\) Once editing is complete, type "REFCLOSE" to save and confirm the changes.
