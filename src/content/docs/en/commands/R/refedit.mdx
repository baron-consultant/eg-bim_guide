* A command that lets you directly edit a block or external reference object inserted in the drawing without exploding it.

![][image1]

## **1\. Editing a Block or External Reference** [**Demo Video**](https://youtu.be/5mpd2qpXZk0)

1\) Type "REFEDIT" in the Command Input Window.  
2\) In the drawing, select the block or external reference (Xref) to edit.  
3\) The selected object switches to the edit set, and its internal components are activated.  
4\) Make the necessary modifications (move, delete, add, etc.).  
5\) Once the modifications are complete, type "REFCLOSE" in the Command Input Window.  
6\) Select either Save or Discard.
