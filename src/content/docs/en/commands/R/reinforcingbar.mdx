* Automatically creates a rebar splice.

![][image1]

## **1\. Creating a Rebar Splice** [**Demo Video**](https://youtu.be/B1bF59Fl7vY)

1\) Type "REINFORCINGBAR" in the Command Line.  
2\) Following the Command Line prompts, select points.

- First point: Rebar splice start point  
- Second point: Rebar splice end point

3\) The rebar splice is created along the selected line.
