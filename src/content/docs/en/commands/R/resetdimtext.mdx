[image1]: ../../../../../assets/images/en/commands/resetdimtext/image1.png

* Restores dimension text that has been moved or manually edited to its original position.

![][image1]

## **1\. Restoring the Dimension Text Position** [**Demo Video**](https://youtu.be/AyES5G8CC_U)

1\) Type "RESETDIMTEXT" in the Command Input Window.  
2\) Select the dimension object to restore to its original position.  
3\) Press the ENTER key.  
4\) The text of the selected dimension is automatically restored to its default position (center).
