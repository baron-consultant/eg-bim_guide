- Rotates the selected object around a specified base point.

![][image1]

## **1\. Rotating an Object** [**Demo Video**](https://youtu.be/kHaDiJHMmD0)

1\) Run the "ROTATE" or "RO" command.  
2\) Select the object to rotate (line, polyline, circle, rectangle, etc.).  
3\) Press ENTER to complete the selection.  
4\) Specify the base point for the rotation.  
5\) Enter the rotation angle.

- Positive (+) → Rotates counterclockwise
- Negative (–) → Rotates clockwise

6\) Press the ENTER key or the Space bar.  
7\) The selected object is rotated around the base point by the entered angle.
