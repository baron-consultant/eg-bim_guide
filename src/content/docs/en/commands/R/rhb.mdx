- Creates the boundary of a hatch area as a polyline.
- RHB can only be used if a Hatch object exists in the drawing.

![][image1]

## **1\. Regenerating the Hatch Boundary** [**Demo Video**](https://youtu.be/cEQz44Exq_U)

1\) Run the "RHB" command.  
2\) Select the hatch whose boundary is to be regenerated.  
3\) Press the ENTER key or the Space bar to create the hatch boundary.  
![][image2]
