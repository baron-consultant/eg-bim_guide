[image1]: ../../../../../assets/images/en/commands/rezen/image1.png

* A command that recalculates the current drawing's display data to regenerate the screen.

![][image1]
 
## **1\. Refreshing the Screen** [**Demo Video**](https://youtu.be/5J8LLvrHZRM)

1\) Type "REGEN" in the Command Input Window.  
2\) Press the ENTER key.  
3\) The current view is recalculated and the screen is refreshed.
