- Controls whether the path to an inserted reference file is saved as an absolute path, a relative path, or no path.

![][image1]

## **1\. Setting the External Reference Path Type** [**Demo Video**](https://youtu.be/ER_IvusSgaw)

1\) Run the "REFPATHTYPE" command in the Command Input Window.  
2\) Enter a value (option).

- 0: Absolute path  
Saves the full path of the reference file (C:\Project\Xref\file.dwg)
- 1: Relative path  
Saves the path relative to the location where the current drawing is saved (..\Xref\file.dwg)
- 2: No path  
Saves only the file name (file.dwg)

3\) Press the ENTER key or the Space bar.  
4\) The path type is applied to reference files inserted from then on.  
Note: The configured path type can be checked in the "XREF" command after inserting the external file.
