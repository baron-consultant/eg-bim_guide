- Rotates the selected object in 3D space around a specified axis.

![][image1]

## **1\. Rotating an Object in 3D** [**Demo Video**](https://youtu.be/JwiNsSsiKnw)

1\) Run the "ROTATE3D" or "3RO" command.  
2\) Select the object to rotate (3D solid, surface, 3D polyline, etc.).  
3\) Press ENTER to complete the selection.  
4\) Specify the axis of rotation.

- Specify the rotation axis by selecting two points, or
- Enter one of the X, Y, or Z axes.

5\) Enter the rotation angle.

- Positive (+) → Rotates in the direction given by the right-hand rule
- Negative (–) → Rotates in the opposite direction

6\) Press the ENTER key or the Space bar.  
7\) The selected object rotates in 3D according to the specified axis and angle.
