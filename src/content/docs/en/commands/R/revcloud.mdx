- A command that draws a revision cloud.
- You can draw a revision cloud, or convert an existing object into a revision cloud.

![][image1]

- Option keywords for drawing a revision cloud

* Arc length: Sets the minimum/maximum arc length of the revision cloud.
* Entity: Converts an object into a revision cloud.
* Style: Sets the style of the revision cloud.

![][image2]

- Style option keywords for the revision cloud

![][image3]

- Direction option keywords for the revision cloud

* If the Yes keyword is selected, reverses the direction of the currently drawn revision cloud.

## **1\. How to Draw a Revision Cloud** [**Demo Video**](https://youtu.be/zBPNkeqSmUA)

1\) Run the "REVCLOUD" command.  
2\) If necessary, select the Arc length/Style keyword to set the revision cloud options.  
3\) Specify the start point on screen with the mouse.  
4\) Move or click the mouse on screen to draw the revision cloud.  
5\) Press C to close the revision cloud, or press ENTER.  
6\) Once you select whether to reverse the direction, the revision cloud is created.

## **2\. How to Convert an Object into a Revision Cloud** [**Demo Video**](https://youtu.be/madsAKxbB-4)

1\) Run the "REVCLOUD" command.  
2\) Select the Entity keyword.  
3\) Select the object with the mouse.  
4\) Select whether to reverse the direction, and the object is converted into a revision cloud.
