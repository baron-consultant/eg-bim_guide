- Draws a one-directional infinite line.
- Draws a straight line that extends infinitely in one direction from the start point.

### Command Options

![][image1]

| Option     | Description                                                                                                                                                                                           |
| :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bisect     | Draws a one-directional infinite line with an angle equal to half the angle between the angle end point and the angle start point (the angle between the one-directional infinite line and the angle start point is \<= 90), by specifying a vertex point and an angle start point. |
| Horizontal | Draws a horizontal line extending to the right from the mouse cursor.                                                                                                                                 |
| Vertical   | Draws a vertical line extending upward from the mouse cursor.                                                                                                                                         |
| Angle      | Draws a one-directional infinite line at the entered angle.                                                                                                                                           |
| Offset     | Draws a one-directional infinite line parallel to the selected line, at the entered offset distance.                                                                                                 |

#### Keywords for Drawing a Parallel One-Directional Infinite Line After Entering the Offset Keyword

![][image2]

| Option                              | Description                                                                                                                          |
| :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------- |
| Through Point              | Freely specifies, with the mouse, the position of the one-directional infinite line to be drawn parallel to the line object.         |
| Through                    | Specifies two points on screen with the mouse, and uses the distance between them as the distance between the line object and the parallel one-directional infinite line. |
| Enter a distance without a keyword | Specifies the distance between the line object and the parallel one-directional infinite line, then specifies with the mouse the position (up, down, left, or right) of the infinite line relative to the line object. |

## **1\. How to Draw a One-Directional Infinite Line** [**Demo Video**](https://youtu.be/bbuZeackg44)

1\) Run the "RAY" command.  
2\) Specify the start point of the infinite line on screen with the mouse.  
3\) Specify the direction of the infinite line on screen with the mouse to draw the one-directional infinite line.  
4\) Press the ENTER key or the ESC key to end drawing the one-directional infinite line.

## **2\. How to Draw a One-Directional Infinite Line Using Two Points** [**Demo Video**](https://youtu.be/GIc0rphN0ro)

1\) Run the "RAY" command.  
2\) Enter the Bisect option.  
3\) Specify the start point of the infinite line on screen with the mouse.  
4\) Specify the angle start point and angle end point on screen with the mouse to draw the one-directional infinite line.  
5\) Press the ENTER key or the ESC key to end drawing the one-directional infinite line.

## **3\. How to Draw a Vertical/Horizontal Infinite Line** [**Demo Video**](https://youtu.be/dNnLNcK45Xk)

1\) Run the "RAY" command.  
2\) Enter the Horizontal keyword (for horizontal) or the Vertical keyword (for vertical).  
3\) Specify the start point on screen with the mouse to draw a horizontal or vertical one-directional infinite line.  
4\) Press the ENTER key or the ESC key to end drawing the one-directional infinite line.

## **4\. How to Draw a One-Directional Infinite Line at a Specific Angle** [**Demo Video**](https://youtu.be/mRljmkgV7CQ)

1\) Run the "RAY" command.  
2\) Enter the Angle keyword.  
3\) Enter the desired angle and press ENTER.  
4\) Specify the start point on screen with the mouse to draw the one-directional infinite line at the entered angle.  
5\) Press the ENTER key or the ESC key to end drawing the one-directional infinite line.

## **5\. How to Draw a One-Directional Infinite Line Parallel to a Line Object** [**Demo Video**](https://youtu.be/oSnUug9NLdk)

1\) Run the "RAY" command.  
2\) Enter the Offset keyword.  
3\) Select an option for drawing the parallel one-directional infinite line.  
&nbsp;&nbsp;&nbsp;&nbsp;3-1) Enter the angle and press ENTER.  
&nbsp;&nbsp;&nbsp;&nbsp;3-2) Specify the distance by specifying two points on screen with the mouse.  
&nbsp;&nbsp;&nbsp;&nbsp;3-3) Enter the Through Point keyword.  
4\) Select the line object that the one-directional infinite line to be drawn will be parallel to.  
5\) Specify the position of the one-directional infinite line with the mouse.  
6\) Press the ENTER key or the ESC key to end drawing the one-directional infinite line.
