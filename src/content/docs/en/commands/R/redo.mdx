title: REDO

[image1]: ../../../../../assets/images/en/commands/redo/image1.png

- Re-executes an action that was undone with the `UNDO` command (undoes the undo).

![][image1]

## **1\. Redoing an Undone Action** [**Demo Video**](https://youtu.be/5IhjzKUyEbE)

1\) Run the "REDO" command, or use the Ctrl \+ Y shortcut.  
2\) The action most recently undone with `UNDO` is re-executed.  
3\) Running it multiple times restores several steps undone with `UNDO`, in order.
