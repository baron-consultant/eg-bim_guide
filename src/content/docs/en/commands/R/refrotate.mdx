- Rotates the selected object to a new angle based on a reference angle.

![][image1]

## **1\. Rotating an Object by Reference Angle** [**Demo Video**](https://youtu.be/xkVGdtlsmCM)

1\) Run the "REFROTATE" command.  
2\) Select the object to rotate (line, polyline, circle, rectangle, etc.).  
3\) Press ENTER to complete the selection.  
4\) Specify the base point for the rotation.  
5\) Specify two points or enter a value to define the reference angle.  
6\) Enter the target new angle.  
7\) Press the ENTER key or the Space bar.  
8\) The selected object is rotated to the new angle entered, relative to the reference angle.
