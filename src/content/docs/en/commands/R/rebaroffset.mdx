* Creates rebar thickness.

![][image1]

## **1\. Creating Rebar Thickness** [**Demo Video**](https://youtu.be/rAlOoyDTbrQ)

1\) Type "REBAROFFSET" in the Command Input Window.  
2\) Following the Command Input Window prompts, select the rebar line.  
3\) Enter the rebar thickness.  
4\) The rebar thickness is created on the selected object.
