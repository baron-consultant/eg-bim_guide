* Resets the Z value of the selected objects in bulk to 0 (default) or a specified value.

![][image1]

## **1\. Changing the Object Z Value** [**Demo Video**](https://youtu.be/vTiD42mHmtY)

1\) Type "REZELEV" in the Command Input Window.  
2\) Select the objects whose Z value is to be reset (mainly 2D objects such as lines, polylines, arcs, circles, and text).  
3\) Enter the new Z value. (Default: 0\)  
4\) The Z value of the selected objects is changed to the entered value.  
![][image2]
