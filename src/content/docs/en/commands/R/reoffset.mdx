- A command that offsets the selected object at equal intervals.
- Selectable objects are linear objects such as lines, polylines, arcs, ellipses, and splines.

## **1\. Offsetting Multiple Times at Equal Intervals \- Entering the Offset Count** [**Demo Video**](https://youtu.be/BpokTDptQlI)

1\) Run the "REOFFSET" command.  
2\) Select the object to offset incrementally.  
3\) Specify a point in the offset direction with the mouse.  
4\) Enter the distance. (The value cannot be 0 or less.)  
5\) Enter the number of offsets.

## **2\. Offsetting Multiple Times at Equal Intervals \- Specifying the Start Point with Two Points** [**Demo Video**](https://www.youtube.com/watch?v=lscpdsDY0r0)

1\) Run the "REOFFSET" command.  
2\) Select the object to offset incrementally.  
3\) Specify a point in the offset direction with the mouse.  
4\) Enter the distance. (The value cannot be 0 or less.)  
5\) Specify the start point using two points with the mouse.
