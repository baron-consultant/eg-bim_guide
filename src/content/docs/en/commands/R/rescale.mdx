- Rescales an object inserted in the drawing to a specified ratio or unit.

![][image1]

## **1\. Rescaling** [**Demo Video**](https://youtu.be/HD8Z1NBy6hw)

1\) Type "RESCALE" in the Command Line.  
2\) Select the object whose size is to be changed (block, external reference, dimension, etc.).  
3\) Enter the desired scale option.

- Scale Factor: Enlarges/reduces the object according to the scale value
- Units: Converts units, for example, from Inches to Millimeters

4\) Press ENTER to resize the selected object to the new size according to the specified value.
