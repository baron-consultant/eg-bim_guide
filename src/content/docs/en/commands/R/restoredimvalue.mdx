[image1]: ../../../../../assets/images/en/commands/restoredimvalue/image1.png

* Restores a dimension value that has been edited or overwritten to its original value.

![][image1]

## **1\. Restoring a Dimension Value** [**Demo Video**](https://youtu.be/YHd--yLtDHg)

1\) Type "RESTOREDIMVALUE" in the Command Line.  
2\) Select the dimension object.  
3\) Press the ENTER key.  
4\) The manually entered text on the dimension is deleted, and the actual dimension value is automatically displayed again.
