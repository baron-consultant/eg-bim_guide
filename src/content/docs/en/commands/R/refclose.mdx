* Ends editing of a block or external reference (Xref) that is being edited with the REFEDIT command.

![][image1]

## **1\. Ending Block Editing** [**Demo Video**](https://youtu.be/v27v6u1tzDc)

1\) Type "REFEDIT" in the Command Input Window to start editing a block or external reference.  
2\) Modify the object to be edited.  
3\) Type "REFCLOSE" in the Command Input Window.  
4\) Select one of the two options below.

| Option | Description |
| :---: | ----- |
| Save | Saves the edited content to the original block or external reference file. |
| Distcard | Discards the changes and reverts to the original state. |

5\) End block editing.
