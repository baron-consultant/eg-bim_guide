- Changes the justification (alignment reference point) of a selected text object.

![][image1]

## **1\. Change the Text Justification Point** [**Demo Video**](https://youtu.be/WhQUtzxEa1g)

1\) Run the "JUSTIFYTEXT" command in the Command Input Window.  
2\) Select the text object whose justification you want to change.  
3\) Specify the desired justification option in the Command Input Window.

- Left(L)
- Middle(M)
- Right(R)
- TopLeft(TL) / TopCenter(TC) / TopRight(TR)
- MiddleLeft(ML) / MiddleCenter(MC) / MiddleRight(MR)
- BottomLeft(BL) / BottomCenter(BC) / BottomRight(BR)

4\) Press Enter to change the justification point of the selected text.
