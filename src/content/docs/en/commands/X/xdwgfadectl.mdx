* A system variable that controls the display transparency (fade) of external reference (Xref) drawings inserted in the drawing.

![][image1]

## **1\. Setting Xref Fade** [**Demo Video**](https://youtu.be/03W2RtiwNSw)

1\) Type "XDWGFADECTL" in the Command Line.  
2\) Enter a display intensity value between 0 and 90.  
3\) The higher the value entered, the fainter the display of the external reference.  
Note: If the change is not reflected on screen immediately, refresh the screen using the "REGEN" command.
