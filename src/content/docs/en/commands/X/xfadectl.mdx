[image1]: ../../../../../assets/images/en/commands/xfadectl/image1.png

* A system variable that controls the degree of background fade for external references (Xref) or blocks in the reference editing view.

![][image1]

## **1\. Setting Background Fade During Editing** [**Demo Video**](https://youtu.be/hP68lCEIZvc)

1\) Type "XDWGFADECTL" in the Command Input Window.  
2\) Enter a display intensity value between 0 and 90.  
3\) The higher the value entered, the fainter the display of the external reference.
