[image1]: ../../../../../assets/images/en/commands/xypoint/image1.png

- Automatically extracts or marks the X, Y coordinate values of a specified point in the drawing.

![][image1]

## **1\. Displaying Coordinates** [**Demo Video**](https://youtu.be/tqyysnA2lds)

1\) Type "XPY" or "XYPOINT" in the Command Input Window.  
2\) Following the Command Input Window prompts, click the point where you want to display the coordinates.  
3\) The X, Y coordinate values of the selected point are displayed in the drawing.
