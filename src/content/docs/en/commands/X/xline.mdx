- Creates a bidirectional infinite line.
- Draws a straight line that extends infinitely in both directions from the start point.

#### Bidirectional infinite line drawing option keywords

![][image1]

| Option       | Description                                                                                                                                                                                             |
| :--------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bisect     | Specify a vertex point and an angle start point to draw a bidirectional infinite line at an angle equal to half the angle between the angle start point and the angle end point (the angle between the bidirectional infinite line and the angle start point \<= 90). |
| Horizontal | Draws a horizontal bidirectional infinite line.                                                                                                                                                                 |
| Vertical   | Draws a vertical bidirectional infinite line.                                                                                                                                                                 |
| Angle      | Click Reference to reference the angle of another object, or draw a bidirectional infinite line at a specified angle.                                                          |
| Offset     | Draws a bidirectional infinite line parallel to the selected line, at the specified offset distance.                                                                                                                    |

#### Keywords for drawing a parallel bidirectional infinite line after entering the Offset keyword

![][image2]

| Option                       | Description                                                                                                                            |
| :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------- |
| Through Point              | Freely specify, with the mouse, the position of the bidirectional infinite line to be drawn parallel to the line object.                                                              |
| Through                    | Specify two points on screen with the mouse, and use the distance between them as the distance between the line object and the parallel bidirectional infinite line.                  |
| Entering a distance without a keyword | Specify the distance between the line object and the parallel bidirectional infinite line, then use the mouse to specify the up/down/left/right position of the bidirectional infinite line relative to the line object. |

<br />

## **1\. How to Draw a Bidirectional Infinite Line** [**Demo Video**](https://youtu.be/ZMrej7K6ZqQ)

1\) Run the "XLINE" command.  
2\) Specify the start point of the infinite line with the mouse on screen.  
3\) Specify the Direction of the infinite line with the mouse on screen to draw the bidirectional infinite line.  
4\) Press ENTER or the ESC key to end drawing the unidirectional infinite line.

## **2\. How to Draw a Bidirectional Infinite Line Using Two Points** [**Demo Video**](https://youtu.be/nJnh48n6Hs0)

1\) Run the "XLINE" command.  
2\) Enter the Bisect option.  
2\) Specify the start point of the infinite line with the mouse on screen.  
3\) Specify the angle start point and angle end point with the mouse on screen to draw the bidirectional infinite line.  
4\) Press ENTER or the ESC key to end drawing the bidirectional infinite line.

## **3\. How to Draw a Vertical/Horizontal Infinite Line** [**Demo Video**](https://youtu.be/_DBF5iyw57Y)

1\) Run the "XLINE" command.  
2\) Enter the Horizontal keyword (horizontal) or the Vertical keyword (vertical).  
3\) Specify the start point on screen with the mouse to draw a horizontal or vertical bidirectional infinite line.  
4\) Press ENTER or the ESC key to end drawing the bidirectional infinite line.

## **4\. How to Draw a Bidirectional Infinite Line at a Specific Angle** [**Demo Video**](https://youtu.be/GWJYmFtd4Lw)

1\) Run the "XLINE" command.  
2\) Enter the Angle keyword.  
3\) Click Reference to reference an object, or enter the desired angle and press ENTER.  
3\) Specify the start point on screen with the mouse to draw a bidirectional infinite line at the specified angle.  
4\) Press ENTER or the ESC key to end drawing the bidirectional infinite line.
