* A command that controls whether the clipping boundary of external reference (Xref) or block reference objects inserted in the drawing is displayed.

![][image1]

## **1\. Setting XREF Frame Display** [**Demo Video**]()

1\) Type "XCLIPFRAME" in the Command Input Window.  
2\) Enter a value to specify the frame display state.

| Value | Description |
| :---: | ----- |
| 0 | Does not display the frame; it also does not appear when printed. |
| 1 | Displays the frame; it is also printed. |
| 2 | Displays the frame; it is not printed. |

3\) Press the ENTER key to apply the setting.  
Note: If the change is not reflected on screen immediately, refresh the screen using the "REGEN" command.
