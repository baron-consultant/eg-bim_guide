* A system variable that sets whether external reference (Xref) objects can be edited directly within the drawing.

![][image1]

## **1\. Setting Up Xref Editing** [**Demo Video**]()

1\) Type "XEDIT" in the Command Input Window.  
2\) Enter one of the following values.

| Input Value | Description |
| :---: | ----- |
| OFF | External references (Xref) cannot be edited within the drawing. That is, the REFEDIT command and double-click editing are unavailable. |
| ON | External references (Xref) can be edited directly within the drawing. That is, the REFEDIT command can be used (default). |

3\) Press the ENTER key to apply.
