- Scales a selected object up or down using different ratios for the X-axis and Y-axis.

![][image1]

## **1\. Scaling an Object (Separate X, Y-Axis Ratios)** [**Object Enlargement Demo Video**](https://youtu.be/qqP28tgr3sI) [**Object Reduction Demo Video**](https://youtu.be/Wy6Y-Bcpelw)

1\) Run the "XYB" or "XYBSCALE" command.  
2\) Enter the X and Y-axis scale factors.

- \> If greater than 1, the object is enlarged (e.g., entering 2 → 2x enlargement).
- \< If less than 1, the object is reduced (e.g., entering 0.5 → reduced to half size).

3\) Select the object to resize (line, polyline, circle, rectangle, etc.).  
4\) Specify the base point (the point that stays fixed during scaling).  
5\) The selected object is scaled according to the entered ratio.
