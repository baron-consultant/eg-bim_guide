* A function that controls whether a group's bounding box is displayed on the drawing screen.  
* This setting does not affect the group itself — it only changes the on-screen display.

![][image1]

## **1\. Setting Group Display** [**Demo Video**](https://youtu.be/fsXjdxt5sEg)

1\) Type the "GROUPDISPLAYMODE" command in the Command Input Window.  
2\) Enter the desired value.

- 0: Does not display a bounding box when a group is selected  
- 1: Displays a simple dashed rectangular bounding box when a group is selected  
- 2: Displays a more prominent rectangular bounding box when a group is selected  
- 3: Displays the bounding box along with highlighted selection handles on the objects when a group is selected
