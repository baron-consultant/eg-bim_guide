- A function that immediately opens the website/file link connected via a hyperlink.

![][image1]

## **1\. Adding an Object Hyperlink** [**Demo Video**](https://youtu.be/dbSBQFoNXvU)

1\) Run the "GOTOURL" command.  
2\) Select the object with the hyperlink set (line, polyline, block, image, etc.).  
3\) The link contained in the object is opened immediately.  
![][image2]
