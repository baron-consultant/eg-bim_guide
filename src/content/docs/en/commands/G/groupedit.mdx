[image1]: ../../../../../assets/images/en/commands/groupedit/image1.png

- A function that lets you add or remove objects from an already created group.
- You can modify the group's components without ungrouping it.

![][image1]

## **1\. Editing a Group** [**Demo Video**](https://youtu.be/yTF3YUz9lJs)

1\) Type the "GROUPEDIT" command in the Command Line.  
2\) Select the group to modify, or enter the group name.  
3\) Enter one of the following options.

- Add: Add new objects to the group
- Remove: Remove specific objects from the group
- ?: Check the names included in the current group
- reName: Rename the group

4\) Press ENTER or the SPACE BAR to apply the changes.
