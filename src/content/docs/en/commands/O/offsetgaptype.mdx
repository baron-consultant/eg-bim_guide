- Changes how corners between objects are handled when offsetting (OFFSET) a polyline.

![][image1]

## **1\. How to Use** [**Demo Video**](https://youtu.be/AwoxGEMhg7I)

1\) Run the "OFFSETGAPTYPE" command in the Command Line.  
2\) Enter the desired value (0 \- Default, 1 \- Fillet, 2 \- Chamfer)  
3\) Press ENTER to change the OFFSETGAPTYPE variable value.  
4\) Afterward, when you run the OFFSET command, the changed corner-handling method is applied.  
![][image2]  
0 \- Default 1 \- Fillet 2 \- Chamfer
