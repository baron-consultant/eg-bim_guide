* Controls whether the frame (border) of an OLE object inserted in the drawing is displayed.

![][image1]

## **1\. Setting OLE Frame Display** [**Demo Video**](https://youtu.be/CNeWsvXVAIM)

1\) Type "OLEFRAME" in the Command Line.  
2\) Enter a value to specify the frame display state.

| Value | Description |
| :---: | ----- |
| 0 | Does not display the frame; it also does not appear when printed. |
| 1 | Displays the frame; it is also printed. |
| 2 | Displays the frame; it does not appear when printed. |

3\) Press the ENTER key to apply the setting.  
Note: If the change is not reflected on screen immediately, use the "REGEN" command to refresh the screen.
