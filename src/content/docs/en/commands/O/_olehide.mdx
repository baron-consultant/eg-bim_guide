* Controls whether OLE objects inserted in the drawing are displayed.

![][image1]

## **1\. Hiding / Showing OLE Objects** [**Demo Video**](https://youtu.be/q2sl-Yz5JkE)

1\) Type **"OLEHIDE"** in the Command Input Window.  
2\) Select or enter one of the following values.

| Value | Description |
| :---: | ----- |
| 0 | Keeps OLE objects displayed (On). (default) |
| 1 | Sets OLE objects to hidden. |

3\) Press the ENTER key.  
Note: Use the "REGEN" command to refresh the screen.
