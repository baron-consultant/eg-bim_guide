title: OFFLAYON
---

[image1]: ../../../../../assets/images/en/commands/offlayon/image1.png

- This command reverses the On/Off state of all layers in the current drawing.

![][image1]

## **1\. Reversing Layer ON/OFF States** [**Demo Video**](https://youtu.be/f8iD4M7gzkU)

1\) Type the "OFFLAYON" command in the Command Input Window.  
2\) Press the ENTER key.  
3\) All layers that are currently on are turned off, and all layers that are off are turned on.
